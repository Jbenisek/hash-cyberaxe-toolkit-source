# Exact-source extraction helper

Part of the HASH$CyberAxe Toolkit. Snapshot: November 5, 2026.

## What it does

A standard-library Python tool that retrieves one original artifact from a local or hosted compact library.

## What this adds to the workflow

Before: Uploading tens of thousands of standalone files or downloading an entire research tree to inspect one source.

What we added: Keeps exact source bytes and SHA-256 verification while using indexed ZIP members and HTTP byte ranges where supported.

- Source collection & instructions: `compact-edition.html`
