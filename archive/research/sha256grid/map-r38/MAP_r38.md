## 2. Leader 0ae69bcb (0xshikhar, 72.64) and runner-up 2f30479f (0xshikhar, 76.12)

**Source.** ePrint 2026/1120 (Li, Zhang, Li, Liu, Qian, Zhu): 38-step characteristic, two-bit conditions and
semi-free-start pair (Tables 3-5). Two-block memory-efficient framework [LLWS26] = ePrint 2026/1080. Characteristic
found with the open-source SAT/SMT tool [LLW24a]. The construction, program, evidence and text are qkniep's
(8bc7d6c5 → 3b532546 → c99df2dc). It in turn reuses winglock's 20a43626/3d819a4b (transcription, exact F7 set,
SMC design) and leech1996's b99301f4 ledger pattern.

**Blocks.** Two. M0 is a uniform first block and gives CV1. The second block carries the differential: M1 and M1' differ
in W7..W11 and W15. The common padding block keeps the collision. The paper's dense part is kept for A3..A13,
E7..E13 and W11..W15. A0, A1 and A2 are freed:

* **Variants.** 256 A0 values (top |R(A0)|, each about 2^29.48 pairs); a 768-value A2 list in 96 classes of equal
  c9; every A1 that passes the exact validity test (E cells of rows 4..8, published dW and ds0 of W8..W11). That
  gives 2^37.48 variants per chaining value (filed). Each valid variant reproduces rows -4..15 and every difference
  that reaches row 16 onward.
* **Dense part / message modification.** No neutral bits. The free words *are* the modification. Row 16 (2^-27) is
  moved into a table. W16 = s0(Y + A1) - A1 + Z0 + c9(A2), where (Y, Z0) depends only on (CV1, A0). The 32 good
  W16 values form an affine set. Table T_j has 2^64 buckets over (Y, Z0) and lists the variants of A0_j whose row
  16 holds: mean 5.59 entries, at most 344,064 (exact bound). Memory is about 2^79.92 bytes (reported only).
* **Online per group** (one first block): 1 compression (charged 1 unit) + 64 prologue + 256 x [29 (+1) A0 block +
  10 per bucket entry (W7 = c7 - A_{-1}, one F7 bitmap load) + 66 per W7 pass (row-17 first test, 10-bit E17 mask,
  2^-10) + 26 + 3,132 per first-test pass (A17, rows 18..37 deep path)] + 15 epilogue. At the caps that is 117.0
  ops per (CV, A0) (filed). The split of a group's cost (DERIVED from the filed counts) is:

  | part | share |
  |---|---:|
  | bucket entries | 44.4% |
  | A0 blocks | 23.5% |
  | W7-pass row-17 paths | 19.9% |
  | first-block compression | 8.35% |
  | deep paths | 3.6% |
  | control | 0.24% |

* **Search engine and batching.** Scalar 32-bit words in 256-bit registers (vt38.py op-counting interpreter, 41
  registers). There is no SWAR or bit-slicing anywhere in the online program. Groups are independent (fresh coins).
  Fixed caps NE/NW/N1 hold the entry count at 1 + 2^-6, W7 passes at 1 + 2^-5 and first-test passes at 4x their
  expectation, with Hoeffding over groups.
* **Ledger (filed; rebuilt exactly, COMPUTED 72.633442).**

  | term | value |
  |---|---|
  | allowances | 2^71.01123 (A_C 2^70, A_S 2^70, DEV 2^64), 32.5% of T |
  | online | 2^72.01600 |
  | table and enumeration preprocessing | 2^67.21233 |
  | N_G | 2^68.43337 groups |
  | success | >= 0.3960005, with 2% slack in N_G |

  With no allowances the total would be 2^72.06675 (COMPUTED).

**Checked and ruled out (DERIVED).**
* Pre-filtering W7 inside the tables would need x = A_{-1} in the index: 2^96 buckets per A0, past any preprocessing
  budget.
* r37-style c7-classes (one W7 test decides a whole class) do not carry over. Here c7 depends on A1 through
  MAJ(A2, A1, A0) and CH(E6, E5, E4) with E5 = A1 + const, so classes do not collapse.
* Indexing rows 17+ by table needs W2, which depends on five chaining-value words.
* More A0 values only amortize the 8.35% first-block share, about -0.06 bit, and double the table preprocessing.
