# w5: does E1's real rate depend on the context word w5? (lever 14, 2026-10-09, local, nothing submitted)

**Verdict: CLOSED.** No w5 class beats the average. Pre-chosen classes do not replicate. The measured gain is 0 within ±0.02 bit for single-bit classes. GUESS ≤ 0.12 bit is replaced by MEASURED ≤ 0.03 bit (2 SE).

## What was run
- **Code.** prereg8 binary, unchanged (validated build), ctx arm, k = 512, all 2^19 members per context (2^28 trials per context). w5 per context comes from an automatic Python transcription of `prereg8/lines8.cuh` (`w5_analyse.py`).
- **Port check (MEASURED).** Every dumped E1L hit was recomputed in Python through the ported ctx_pre8 → mem_eval8 → E1 path, with tau, eps and beta compared: **26,784 / 26,784 OK** (13,375 main + 13,409 fresh). This validates the w5 values used for the split.
- **Discovery set.** prereg8 `main/` ctx-arm records (read only): 2^18 contexts, **2^46 trials**, G1 and G2. The best classes were picked and written to `selection.json` before any fresh data was read.
- **Confirmation set (new).** New label keys (`fresh/keys.json`): 2^18 contexts, **2^46 trials**, G1 and G2, 563.7 s of GPU kernel time, beta_bad 0, no hit overflow.
- **Pooled.** 2^47 trials, 26,784 E1L, 4.19e10 E1a.

## X9 (DERIVED from lines8.cuh, MEASURED by `x9_check.json`)
- **Inputs.** w5 depends only on S11, S4, X9 and w6 (outer words 3, 4, 5, 6).
- **X9 alone sets w5.** With the other three fixed, X9 → X14 → D3_d1 → S14 → S2 → w5 is a bijection. Solving X9 for a target w5 hit 2000/2000. The other six outer words are unchanged.
- **Derived values that also change:** w2, w3, w12, S1, S2, S5, S6, S9, S10, S14, X4, X14, C0_b1, K1_a1, K1_b1, K1_c1 and K1_d1. X9 also enters every member through C1_c1. So the restriction is free in supply, but it is not a change of w5 alone.

## Why it is null (DERIVED)
- w5 enters E1 only through a2 = a1 + b1 + w5.
- For fixed c1 with (Y12, KY) uniform, a1 is uniform and b1 is uniform and independent of it. So a2 given (c1, b1) is uniform, and the event rate does not depend on w5 at all.
- The measurement agrees: the member loop's (Y12, KY) is close enough to uniform at these depths.

## Limits
- Only E1L and E1a were measured, not full listed good trials.
- Single bits and the low byte only. Higher bytes and multi-bit patterns were not tested one by one, but bit-wise sums of z² near df argue against a strong pattern.
- The GPU was shared, which affects throughput only.
