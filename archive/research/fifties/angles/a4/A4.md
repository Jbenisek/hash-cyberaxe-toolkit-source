# A4: multi-length k-tuplets on one base (ANGLES.md section 4) - CLOSED

Verdict: **CLOSED.** No choice of the six pins (X3, X7, X11, X15, W4, W13) lets round-1 C3 keep Y7 and Y15 equal for
three block lengths. This holds for every set of lengths, every IV or chaining value, and every flags/counter
setting. The stage-1 rate test was not run because no pin set exists to run it on.

## Test (brief: {55, 63, L3}, L3 in {47, 59, 61, 62}, kissat --time=600)
CNF on the six pin words (192 variables; 2,451 variables and about 10,300 clauses after bit-blasting). For each L
in {63, L3}, the C3 b and d outputs at m4_L = ((W4 + K) xor 55 xor L) - K equal those at m4 = W4 (the 55 side;
outer.py line 40). Format constraints: the W13 top byte is 0 (byte 55 is padding), and W13 = 0 for L3 = 47.

| L3 | kissat (MEASURED) | wall | cadical | cryptominisat5 |
|---|---|---|---|---|
| 47 | UNSAT | 0.76 s | UNSAT | UNSAT |
| 59 | UNSAT | 0.58 s | UNSAT | UNSAT |
| 61 | UNSAT | 0.34 s | UNSAT | UNSAT |
| 62 | UNSAT | 0.05 s | UNSAT | UNSAT |

Controls (MEASURED):
- With the documented pins fixed, {55, 63} is SAT and {55, 63, 59} is UNSAT, which agrees with ANGLES M2.
- With free pins, {55, 63} is SAT in under 1 s. The witness X3=d7abb814 X7=925447ef X11=e7dfce18 X15=023fc3ce
  W4=76000002 W13=00809dc0 was verified in plain Python: Y7 and Y15 are equal, dY3=47f7c477 and dY11=7867fb81.
  So the encoding admits solutions when they exist.
- Dropping the format constraints changes nothing: {55, 63, L3} is still UNSAT for 47, 59, 61 and 62, and for
  every L3 in 1..64 (62 lengths, kissat).

## Why this closes the angle for every IV, and the full sweep
DERIVED: the C3 condition depends only on the XOR masks between the lengths. a_L = X3 + X7 + m4_L = s' + (t xor p_L),
where s' = X3 + X7 - K, t = W4 + K and p_L = 55 xor L. Because X3 and W4 are free, s' and t are free, and K = IV2 + IV6
(h2 + h6 in a later block) drops out. So no IV, chaining value (angle 8), flag or counter choice can add a pin set.
MEASURED (kissat --time=60, no format constraints, no UNKNOWN results):
- Pairs {0, p}, p = 1..127: SAT exactly for the 63 even masks, and UNSAT for all 64 odd masks.
- Triples {0, p, q}, 1 <= p < q <= 127: all 8,001 are UNSAT and none is SAT. That includes the 1,953 triples
  whose pairs are all individually SAT (p and q both even). So there is no set of three lengths at all.

DERIVED: a k-tuplet needs every pair in it to satisfy C3, so with no triple there is no k-tuplet for any k >= 3. The
cap in ANGLES (1.58 bits for k = 3, 2.58 for k = 4) falls to 0. Even masks still give one pin family per mask, but
that is the "other families" route (END_OF_LINE 3.8, 3 to 4 bits poorer), not this angle.

## Not tested
- There is no DRAT proof check: drat-trim is not installed. Three independent solvers (kissat, cadical and
  cryptominisat5) agree on the four brief instances.
- The scheme is only the one this angle names: lengths that differ only in m4 and m5, with K2 cancellation and C3 keeping Y7 and Y15.
  Tuplets that differ in other words were not examined.
