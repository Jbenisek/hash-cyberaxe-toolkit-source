SIZING RULE - perframe (written 2026-10-09 before the timing run; no main-kind key used)
CAP_SECONDS = 2700
MIN_FRACTION = 0.75
Timing: `python3 -B run_main.py timing` (kind 'timing'): 512 frames (G = 2^19 outer steps each) for each of (ctx, G1),
(ctrl, G1), (ctx, G2), (ctrl, G2) at K = 512 and at K = 256; t_K = total wall time / 2048 frames (start-up included).
Choice: K = 512 if 2^19 * t_512 <= MIN_FRACTION * CAP_SECONDS (2^19 = all frames of the main run, both arms),
else K = 256. (run_main.py applies exactly this.)
Main: SEG_FRAMES = 4096 frames per arm and generator per segment, MAX_SEGMENTS = 32 (2^18 frames per arm, 2^17 per
arm and generator); segment s >= 1 starts only if elapsed + duration of segment s-1 <= CAP_SECONDS. Minimum target 16
segments (2^17 frames per arm); a shortfall is reported, not repaired.
GPU budget of the task: at most 75 minutes in all (validation, timing, dry run and main together); the GPU is shared.
