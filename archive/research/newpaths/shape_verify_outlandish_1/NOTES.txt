1. THE LEMMA (DERIVED, checked by brute force)
  Plain model: each primitive equation solves any ONE of its words once all its others are known.
  Claim: a 0-check order exists  <=>  the 2-core of the equation hypergraph (peel: drop an equation that has a word
  occurring in no other remaining equation) is empty.
  Proof.  With 0 checks the guesses number F = vars - eqs, so every equation solves exactly one word (one equation
  cannot solve two words: the first solve needs the second known).  Take the core equation used LAST; it solves a
  core word w; w lies in >= 2 core equations, so another core equation e' was used earlier while w was still
  unknown - impossible (e' needs all its words but its own target known, and its target is not w).  So a non-empty
  core forces >= 1 equation that never solves anything = >= 1 check.  Conversely reverse peeling gives an order.
  Guesses cannot "break" a 2-core (shape_odd/core.py doc line says they must; that is the error).
  lemma_check.py (COMPUTED): 1406 random small hypergraphs (545 with non-empty core), exhaustive over all guess
  sets of size F: lemma agrees 1406/1406.

4. COST ACCOUNTING (DERIVED, contest model literally)
  If the door existed: 1.18 * 2^80 members (160-bit birthday), each ~ one compression of word ops -> ~2^80.2.
  The 2^80 arithmetic is right; its premise c(3) = 0 is false (plain) / unsupported (tables).
  With c(3) >= 1: >= 2^32 rejected attempts per member -> >= 2^(80+32) = 2^112 compression units if an attempt
  costs a compression; even the extreme word-op discount (1 op = 1/430 unit per failed attempt) leaves >= 2^103.
  No 1-check order for k = 3 is known (greedy best is 3 checks -> 2^176, i.e. generic 2^128 is cheaper).
  Note: at the 2^80 level "preprocessing up to 2^85 is negligible" no longer holds; only tables <= ~2^76 work
  would be negligible.  2-dof tables (2^64) are fine.
  32-bit extrapolation: the core argument is structural (word level, every primitive is bijective in each word),
  so it holds at w = 32 exactly; no toy extrapolation is involved.
