MODEL (DERIVED)
  Words W (unknowns), equations E (each primitive G equation, solvable for any one unknown), optional table
  macros of gd_sat.py.  cl(T) = propagation closure.  delta(X) = |X| - Ein(X), Ein(X) = equations with all
  words in X: the generic dimension of region X (each equation one 32-bit condition, assumed independent).
  F = |W| - |E| = family dimension in words (fixed: 4, outhalf: 12).

  Two-list structure.  Core C (enumerated outside, n values), side A, side B (guess words).
  X1 = cl(C+A), X2 = cl(C+B).  Lists: LA = 2^x entries of side A (x <= 32a), LB = 2^y.
  Join key = the independent conditions linking X1 and X2:
      kX = delta(X1) + delta(X2) - |C| - delta(X1 u X2)
  After the join, propagate from X1 u X2; post-join checks p = delta(X1 u X2) - F (needs cl(X1 u X2) = all).
  Internal checks of a side: iA = |C+A| - delta(X1) (filter on the list, costs 2^(32 iA) per kept entry).
  Total checks |S| - F = kX + p + iA + iB, S = C+A+B.   [DERIVED, generic counting]
  If X1 u X2 = all (strict split) then p = 0 and kX = delta(X1)+delta(X2)-|C|-F.

  Cost (log2, unit = one batch of word ops per list entry, one compression per member):
      joined pairs J = nu + x + y - 32 kX, members = J - 32 p, need members = 64.
      cost = 1 + max(nu + x + 32 iA, nu + y + 32 iB, J, 64).
  Lower bound: cost >= 32 + 16 kX + 32 p (balanced lists), so
      kX = 2, p = 0 -> 2^65 ;  kX = 3, p = 0 -> 2^81 ;  kX + p = 4 -> >= 2^97.

  NECESSARY CONDITIONS FOR COST < 2^85 (DERIVED from the formula above, F = 4):
      p = 0, kX <= 3, and either
        kX = 3: iA = iB = 0, a, b >= 3, |C| <= 1, |S| = 7, side guess sets |C+A|, |C+B| <= 4;
        kX = 2: |S| = 6 + iA + iB with iA + iB <= 1, |S| <= 7, side guess sets <= 4.
      In every case cl(S) = all with |S| <= 7.
  The same holds for any target up to 2^96: lists <= 2^95 give kX + p <= 3, so |S| <= 7.  With |S| = 8
  (4 checks) even a perfect split costs >= 2^97, worse than the board (92.2-94).

  R6 DERIVED: jtree = 2^193 for a set S means no proper subset U of S (with any core of <= 2 of its words)

ANSWER (decisive question: does idea 1 work through a list join?)
  No, not in the guess-and-determine model, and not by a small margin.
  - Fixed variant: the minimum guess basis is exactly 8 words (4 checks of 32 bits), proven by exhaustive
    search with no depth bound in the plain model, the gd_sat table model and the 2^64-table model.  A
    two-list join below 2^85 (indeed below 2^96) needs a basis of <= 7 words.  So none exists.
  - Beyond the count: in 200,000 + 2,676 sampled minimal bases the 4 checks are global.  No part of a basis
    produces a check and no two parts share a join key, so joins and multi-level trees give nothing: the best
    cost in the model is 2^193 for 2^64 members (2^128 per member), far above generic birthday 2^128.
  - Outhalf variant: the smallest basis found is 16 words (4 checks) in all models (heuristic local search,
    not exhaustive); a join below 2^85 needs <= 15; every top-level split of 24 found bases has join key 0,
    and the full multi-level DP on one basis per model gives 2^193.
  WHAT IT WOULD TAKE: a basis with one guess fewer (7 for fixed, 15 for outhalf) whose 3 checks are all
  join keys between two sides of >= 3 free words each (|C| <= 1): cost ~2^81.  Two keys and 6 guesses:
  ~2^65.  Today: 8 guesses and 0 keys.  The missing ingredient is a solving technique outside this model
  (something that makes the final-cascade checks computable from one side), not a better search.
  Step 3 (toy end-to-end attack) was not run because no structure below 2^85 exists in the model.
