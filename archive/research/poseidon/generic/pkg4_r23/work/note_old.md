## Approach and why
1. The walk. Fix rho = 0 and set F(x) = digest(x, 0). The digest is a canonical Pallas field element, and a canonical field element is an admissible first input, so the output of F is again an input. No injective map and no conversion operation is needed, and the rule that an input is exactly two canonical 32-byte little-endian encodings holds for every point of the walk. Two inputs (x, 0) and (y, 0) with x != y and F(x) = F(y) are a collision of the target.
2. One trail. Start from a uniformly random 254-bit word x_0 (a fresh coin; every such word is below p), iterate x_i = F(x_{i-1}). A single trail needs only one table: every value whose low 128 bits are below 27554 (density 2^-113.25) is a distinguished point and is stored with its index (48 bytes). When a stored value repeats, the trail has closed on its cycle.
3. Recovery. Let the repeat be x_b = x_a, L = b - a. Take the stored entry just before a (or the start). Compute x_{s+L} by walking from the nearest stored point, then walk both from (x_s, x_{s+L}) in lockstep; the first time the images agree, the two points are the collision (x_{mu-1}, x_{mu-1+L}). The proof (Section 3) shows the entry before a lies before the merge point, so the recovery costs at most 3 gmax evaluations.
4. Why one trail. Under total-work accounting parallel trails add nothing, and a single trail already needs about 1.25 sqrt(N) steps to close; the budget for success 0.39 is 0.994 sqrt(N) steps, plus a detection window and the recovery. The table holds about 13,700 points at that length, inside the free one-MiB band.

## The success lemma (adapted from b4d, with exact field density)
For a uniformly random function F on N = p points, a fresh step hits one of the i + 1 earlier values with probability exactly (i + 1)/N, so P(no repeat in n steps) = prod (1 - (i + 1)/N) <= exp(-n(n + 1)/2N). Further terms: the start lying on the cycle (n/N), no distinguished point in the first d = ceil(8/theta) cycle values (e^-8 + n d/N), a gap above gmax = ceil(18/theta) ((S theta + 1) e^-18, about 2e-4), table overflow (ln probability -241). The density theta = (2^126 + 1) * 27554 / p is the exact fraction of field elements that are distinguished (p = 2^254 + c, c >= 27554); flags of distinct values are hypergeometric, bounded by the product inequality prod (p - theta p - j)/(p - j) <= (1 - theta)^m, and the table count by the Chernoff-Hoeffding tail (Hoeffding 1963, Thm 4). Only closed-form inequalities are used, no numerical moment-generating-function bound and no fitted law, and the final bound is evaluated in 80-digit decimal arithmetic: n is the least multiple of 2^100 with 1 - exp(-n(n + 1)/2N) - n/N - eps >= 0.39 (eps = 1.123e-3): n = 1.6948e38, bound 0.390000000554332285. The probability is over the fresh start coin and the random function; the algorithm has real coins, as the rulings require. Nothing is estimated from sampling.

## Caveats
H1, the random-function premise (score-critical, an assumption, no proof is known): the real walk x -> digest(x, 0) behaves like a random function on a trail of 1.7e38 steps, and distinguished-point flags are independent of the collision events; the trail cannot be observed and no trusted experiment exists (the organizer runner cannot run Poseidon experiments). Sensitivity: if the hazard is (1 - e)/N instead of 1/N, the budget needs 0.0072 bit for e = 0.01, 0.037 for e = 0.05, 0.076 for e = 0.10. H2, the machine convention (supporting): a reference permutation call is one unit and pays for its arithmetic, constants and loads only; the state restoration, the loop and the table are charged as listed; loop variables are registers; code is charged 36 bytes per instruction with 256-bit immediates. If a step cost 20 other operations instead of 9 the time would rise by 0.0223 bit. H3, the table representation (supporting): the array and scan described above, counted from the layout. Nothing else in the claim is heuristic: Lemma 2, the recovery correctness and every count are proved in proof.md. No full-scale run and no collision are claimed. The bound has no margin above 0.39.
