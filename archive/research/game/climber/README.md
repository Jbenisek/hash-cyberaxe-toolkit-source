# Round Climber public research instrument

Round Climber is a browser-based teaching and exploration interface for the
released SHA-256, SHA-3, and Poseidon research records. It presents ladders,
cells, levers, maps, and evidence summaries without publishing private
coordination logs or request queues.

## Public pages

- `arcade.html` — the interactive ladder and climb explanation;
- `encyclopedia.html` — searchable public records;
- `board.html` — the public lever/map view;
- `MAP_README.md` — map and field definitions;
- `SCIENCE_ENGINE_SPEC.md` — model and status semantics.

The browser bundle uses the redacted `kb/knowledge.js` release artifact. Source
paths, private answers, request queues, and coordination notes are intentionally
not part of this public copy.

## Scientific status

The arcade is an explanatory instrument. Its schedule checks are necessary
conditions, not proofs. A result must still be followed to its public evidence,
certificate, and package status in the main library.
