## Caveats on the two new cells

- **(8,8):** the other W8 signings (`=un`, `nnn`, `unn`) collide at 2^-7.39 per candidate, against 2^-3.005 for the printed signing, which is about 21 times worse. The gain is 2.7% more collisions from a W8 pool 57% larger. It is worth something only if W8 candidates per base run short and the extra candidates cost the same to try. The result rests on the published base alone: the 4 SMC bases gave 0 collisions in every class. It is not known whether the attack's A0-variant generator can reach the 6,875,136 extra W8 values; allg_classes lists only the `==u` set. Distance to filing: an SMC-base exact count with error bars, a check that the generator reaches the extra values, and an EX x (8,8) joint run.
- **(16,20):** the attack chooses E20. Per candidate, the other signing succeeds at about 1.3% of the printed signing's rate. The gain counts only if E20 candidates are scarce. It has to be recounted against the attack's free coordinates (E16..E21) before anyone credits it, and a `--carrier none` run was not done.
