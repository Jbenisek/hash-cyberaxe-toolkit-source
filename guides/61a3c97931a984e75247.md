# Signed differences: inspect representations and enumeration modes

## Reviewed usage contract

C implementation of signed-digit representations, sigma-difference counts and backward row analysis. This guide reviews these algorithms; it does not claim a new full-word enumeration or backward-analysis run.

## Source inspection and available execution evidence

static-source-review; not-replayed-for-publication.

tl_sdiff_count visits 4096 blocks of 2^20 values: all 2^32 x. --limit limits printed rows only. Backward --noenum skips optional full-word schedule counts, not the local distribution loop of up to 2^26 exact or 2^24 sampled assignments per side/row. No global memory bound is established for its growing histograms.

## Declared inputs

**Word-level count**: TLSdiffCfg supplies D, function selector and target T for func(x+D)-func(x)=T modulo 2^32. An optional XOR restriction filters the counted domain; an optional callback classifies exact hits against a cell.

**Signed patterns**: tl_bsd returns plus/minus bit masks for D modulo 2^32 under a maximum signed weight. tl_sym prints MSB first: n=(0,1), u=(1,0), '=' for an equal bit.

## Outputs and interpretation

**Counter fields**: domain counts inputs surviving the optional XOR restriction; exact counts the function predicate; cellexact additionally passes the optional cell callback. Without a callback cellexact stays zero, not a claim that exact is empty.

**Backward model**: The Boolean/sigma distribution enumerates relevant free assignments for nf<=26 and otherwise samples 2^24 deterministic-seed draws. It explicitly omits two-bit and '+' conditions. Multiple value-dependent schedule terms are left joint and unenumerated.

## Worked examples

### Inspect a small signed-representation request

Working directory: An independently built TrailLab source bundle

```text
./traillab sdiff --delta 80000000 --maxhw 1 --limit 2 --threads 1
```

Expected: Source analysis selects signed-representation mode because --func is absent. The one-bit modular difference has two signed weight-one representations, +2^31 and -2^31. This command is a source-reviewed example, not a new runtime result.

## Failure modes

- Do not infer exactness from the command name when the backward output explicitly says SAMPLED.
- An optional XOR filter does not reduce the outer full-word scan.
- Local model probabilities omit constraints and do not automatically transfer to the generator.
- An output limit is not a CPU or memory budget.
- Do not interpret cellexact=0 as an empty exact set when no cell callback was supplied.
