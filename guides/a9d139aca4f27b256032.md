## Reviewed usage contract

Check stored schedule witnesses, inverse sigma matrices and late-support incidence lists. Optional flags invoke separate exhaustive C++ and Python workloads; only the quick default was replayed for this guide.

## Source inspection and available execution evidence

static-source-review; default-99-checks-and-six-interface-controls-passed; exhaustive-modes-not-run.

The quick default is bounded by the saved witness sizes and 32-bit basis loops. Full minimum enumeration is a different, potentially enormous workload; no quick-runtime observation prices it.

## Declared inputs

**Quick default**: python verify.py reads data/results.json relative to its own location and imports code/modular.py and code/explore.py. Uses the linear_witnesses, modular_witnesses, sigma_certificates and late_supports fields; descriptive summaries and saved regression labels are not checked.

**Large optional modes**: --recompute-supports and --recompute-minima compile C++ and invoke additional programs and certificates. These are not smoke-test flags; the minimum mode includes billions of vectors. Their complete dependencies are outside the quick teaching kit.

## Outputs and interpretation

**Default console**: PASS: 99 quick replay/certificate checks. The count is 26 linear witness records, four modular witness records, 64 basis checks and five support-group comparisons. No compression collision is checked.

**Files**: Default mode reads sources/data and prints only. Optional modes create a temporary work directory and compiler outputs. Python imports can otherwise create bytecode; examples use -B.

## Imports

- Default: Python standard library and the pinned four-file source/data tree. Full modes: g++, extra Python sources, matrices and certificate files; not reproduced here.

## Worked examples

### Run the bounded standalone kit

Working directory: Extracted sparse-schedule-kit folder

```text
python -I -B replay.py
```

No compiler or research checkout is needed. The kit rejects -O, pins its sources and data, and creates only disposable mutation fixtures.

Expected: passed=true, six interface controls and quick_checks=99. No global minimum or compression collision is certified.

Working directory: Extracted sparse-schedule-kit folder


Do not add the exhaustive flags. This direct diagnostic lacks the kit's outer manifest and count guards.

Expected: PASS: 99 quick replay/certificate checks, followed by the explicit notice that no compression collision claim is checked.

## Failure modes

- Python -O removes the assertion checks yet still prints PASS for a deliberately wrong saved weight. Keep assertions enabled.
- Empty witness dictionaries still print a smaller 69-check PASS. Pin the data and require the expected record counts.
- The quick verifier does not reproduce saved summary minima or historical regression counts.
- A valid linearized XOR schedule is not a native modular differential. A valid native modular schedule pair is not a compression collision.
- Optional minimum comparisons and historical completeness claims require their own audit; they were not executed by this publication check.
