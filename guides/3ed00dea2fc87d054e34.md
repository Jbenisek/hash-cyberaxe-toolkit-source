# Leave-one-out summary: compare refilled rows and fixed-line sets

Source: `research/launch/port/loo_test.py`

Public SHA-256: `28d5c805933dccba30da90e28bef48613f6296ccd1fdc7807d81b1f5503db88a`

## Reviewed usage contract

Build a full template, compare refilled rows in text mode, and summarize changes in fixed-line sets when each row is left out. The source does not run extract.py on the held-out file, so FITS is not an executable fit certificate.

## Source inspection and available execution evidence

static-source-review; synthetic-newline-key-collision-and-heldout-fit-counterexamples-reproduced.

Builds one full template, refills every row, then builds one further template per omitted row. Alignment and retained temporary files grow with the supplied corpus; it is not a cheap constant-time check.

## Declared inputs

**CLI**: python loo_test.py FILE_REL ROWDIR... . Keep mktmpl.py and filltmpl.py beside the script. Use at least two trusted row directories and validate their derived keys are unique.

**Temporary files**: Creates multiple tempfile.mkdtemp directories without removing them itself. Run in a controlled disposable environment with TEMP/TMP/TMPDIR directed inside the test root; the teaching replay does this automatically.

## Outputs and interpretation

**Reconstruction label**: EXACT means equality of Python-decoded text, not bytes. A CRLF input and LF reconstruction can produce EXACT. A reconstruction FAILED label does not force a nonzero exit.

**Held-out labels**: Compares fixed-line membership and numeric skeleton sets, which discard ordering and multiplicity information. Final ALL FIT may also be qualified to allow newly supplied per-row text. Even unqualified ALL FIT can coexist with failure of actual held-out extraction.

## Imports

- Python standard library plus mktmpl.py and filltmpl.py. It does not invoke a cryptographic verifier or inspect a mathematical success law.

## Failure modes

- A reproduced three-row example reports r43 held out: FITS and ALL FIT, but extract.py rejects r43 against the template built from r41/r42.
- Duplicate inferred row keys overwrite values; reconstruction FAILED can still exit zero.
- EXACT normalizes newline differences and must not be called a byte-for-byte certificate.
- A one-row input leaves an empty training set in the omitted-row pass and is unsupported.
- Historical timing and corpus coverage are reported results; the new publication tests use synthetic files only.
