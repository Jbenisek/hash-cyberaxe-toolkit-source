# BLAKE3 B7: seven-round arithmetic and the declared memory charge

## Reviewed usage contract

B7 extends the unrolled binary circuit to seven rounds. Its uniform 36-byte instruction representation already exceeds one MiB before the table. Its numerical helpers also change from the preceding revised six-round source: midpoint quadrature with 1,500 bins replaces 20,000-bin trapezoid quadrature; cut terms and planning margins change. Fresh finite arithmetic and supplied-budget checks do not prove the numerical success model.

## Source inspection and available execution evidence

static-source-review; Own-source finite kernel, compiler-only recipe, synthetic recovery and exact supplied-budget accounting. No optimizer, numerical probability replay or original campaign..

One fixed construction/allocation, checked in a subprocess with a ten-second limit. No numerical optimization or original collision search.

## Declared inputs

**Seven-round target**: One full BLAKE3 block: 32 zero bytes followed by little-endian x. Seven rounds, unit 1470, counter 0, length 64, flags 11 and the standard IV. The walk uses f XOR q, not the unmasked digest.

**Circuit and recovery**: 256 bit-sliced lanes; 45,974 binary main operations, 771 allocated registers, 23 compiled chunks. Recovery packs seven 36-bit lanes and uses 1,540 primitive operations before separately charged handlers.

**Declared representation**: 36 bytes per instruction, 800 declared registers, 10-byte endpoint records, 64-bit keys and 16-bit trail identifiers. The memory limit is 1,912,336 bytes, not one MiB.

**Model boundary**: The loss helper fixes L=2^122/Tp and N=2^256. Reduced-width inputs to its wrapper do not change those constants. The run-length cache omits Sb; clear it or use a fresh process when changing Sb. Mocked controls demonstrate the interface behavior, not that the fixed default is affected.

**Safe finite entry point**: Use the fingerprinted download in a disposable directory. The example only constructs and allocates the circuit. Do not substitute --selftest, --stats, the default planner, an original search or embedded-C generation for this bounded example.

## Outputs and interpretation

**Independent finite arithmetic**: 256 fixed full-width lanes match an independent BLAKE3 reference. Two known answers, two chain steps, reduced 18/20-bit cases, packed recovery fixtures, allocated instruction/chunk checks and two mutation controls pass. Not a universal generator proof.

**Declared phase accounting**: Main=45,974, stage filter=34, batch body=46,011; code=1,755,288 bytes and table=11,500 records. Setup/search phases are 1,874,152 and 1,912,272 bytes. Code alone exceeds one MiB. These are source-model quantities, not measured Python memory or a full handler audit.

**Two distinct memory components**: The allocation limit has log2(memory/2^20)=0.866904598367743642232583584391209095699135383813164916596965. The declared occupied-phase component is 0.866856314997199256029746531594771183319606129899963223282257. Neither is a complete attack score; retain the chosen historical memory convention.

**Trail and field boundaries**: The start envelope 256+11,500+1+1=11,758 fits the 65,536-value trail field. Four nonnegative packing roundtrips and two upper-bound rejections pass. Negative -1 aliases unsigned all-ones fields; callers must validate nonnegative inputs.

**Supplied-budget ledger**: For Tp=22, kappa=13 and B=10^35, independently expanded components sum to N=14680031730872080002177952968869349159272. Recovery is charged twice at 1,540+64=1,604 operations per batch, plus 600. The supplied budget does not establish a successful, default or optimized attack.

**Artificial interface fixtures**: Six one-batch search branches and four endpoint-recovery graphs pass. The graphs require 5, 7, 4 and 2 calls respectively. They check program behavior, not real BLAKE3 collision witnesses.

## Failure modes

- Use this seven-round source and reference unit 1470; earlier-round charges do not transfer.
- Do not claim this code fits below one MiB.
- Do not infer a complete attack score from the memory component or supplied-budget numerator.
- A revised numerical helper does not by itself prove a probability theorem or target-transfer assumption.
- Finite fixtures are not an independent audit of every machine handler, C/wasm generator or historical adjudication.
