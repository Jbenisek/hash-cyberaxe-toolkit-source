# Backward-demand heuristic: compute the exact stopping score

Source: `research/tools/profile/backscore.py`

Public SHA-256: `8fadd907d747114b77f587d4d4f7b7c376cd5fad49145d21cbbc8d54e0826ba4`

## Reviewed usage contract

Inspect the pure walk and signed-digit-weight functions without running the original hardwired file-discovery and output writer.

## Source inspection and available execution evidence

static-source-review; two-extracted-pure-functions-checked-on-7584-difference-vectors-and-8193-NAF-inputs; driver-not-run.

Bounded arithmetic on at most 64 difference rows per call. No full campaign or solver timing measured.

## Declared inputs

**Pure walk(dW,R)**: Canonical 32-bit modular word differences and a step count 1..64 with sufficient entries. The function does not provide a complete external-input validator.

**Original script driver**: Discovers specific project pair paths and LIT_PAIRS.jsonl, imports indep_sha256_check, then overwrites BACKSCORE.tsv beside the source. It is not a generic read-only CLI.

## Outputs and interpretation

**depth,knot,demand**: All-zero differences give (R,-1,0). Otherwise for final nonzero index j: (R-j,j-1,NAF_weight(-dW[j] mod 2^32)). knot is the stopping step, not the beginning of its dependency window.

**score**: demand+2*max(0,8-depth). An exact heuristic scalar, not a proven probability exponent or complete attack charge.

## Imports

- Pure functions need only Python builtins and M=2^32-1. The original writing driver additionally imports the project SHA-256 module and expects its hardwired input tree.

## Worked examples

### Evaluate the pure diagnostic without executing its writer

Working directory: Directory containing the downloaded backscore.py

```text
python -c "import ast; t=ast.parse(open('backscore.py').read()); f=[n for n in t.body if isinstance(n,ast.FunctionDef) and n.name in ('walk','naf_weight')]; ns={'M':2**32-1}; exec(compile(ast.Module(body=f,type_ignores=[]),'<fixture>','exec'),ns); print(ns['walk']([1]+[0]*7,8))"
```

Expected: (8, -1, 1). This gives heuristic score 1, not proof of a common-IV collision.

## Failure modes

- A hypothetical clean end need not be reachable from a common IV or selected prefix.
- The stop rule is sufficient for easy exact propagation, not a theorem that nonzero-input propagation is impossible.
- The score can be one for an eight-step pattern that provably cannot coalesce from a shared initial state.
- Running the original script overwrites its local BACKSCORE.tsv.
- Malformed pair files and out-of-range target steps are not comprehensively validated.
