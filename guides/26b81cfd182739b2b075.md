# W11 class enumerator: count the local word domain

Source: `research/game/climber/guided/n39steer/classes.py`

Public SHA-256: `b56fdf584d0e81e35b15b1ad49d60057f887989ae7b0af2b3605e4ae72fc83dc`

## Reviewed usage contract

Enumerate every assignment of the free dash bits in base39.xml's W11 row, compute the modular small-sigma difference, and count each resulting word class. Labels seen and UNSEEN describe a separate saved table, not cryptographic validity or a solver verdict.

## Source inspection and available execution evidence

static-source-review; four-value-synthetic-enumeration-and-sanity-failure-controls-passed; historical-full-enumeration-not-rerun.

For f free bits the script materializes uint64 arrays of length 2^f and sorts classes through numpy.unique. For the historical f=23 row, each such array alone occupies 64 MiB; several arrays and expression/sort temporaries coexist. This is not a low-memory streaming counter. Use the rank certificate for the archived row rather than allocating the full domain just to verify its count.

## Declared inputs

**Working directory**: No CLI arguments. Run only from an isolated copy of research/game/climber/guided/n39steer containing base39.xml, with the exact relative sibling luna_found/FOUND_li39_tab23_s1.txt and research/pkg_r39_combined/work/tail_var/VALUE_MAP.txt locations. Running in place replaces the original class table.

**Signed row**: Reads the row numbered 11. Characters are interpreted most-significant-bit first: n fixes X=1, u fixes X=0, and dash is a free X bit. Y=X+delta modulo 2^32, where delta is the sum of u bit weights minus the sum of n bit weights. Validate exactly 32 symbols from u,n,- before use; the source does not enforce this schema.

**Saved pair and membership table**: The pair parser expects lowercase hexadecimal M1: W= and M2: W= lines. VALUE_MAP rows with exactly five whitespace fields contribute their first field as a case-sensitive class string. The pair is a printed sanity example, not a prerequisite enforced by an assertion.

## Outputs and interpretation

**class_set_W11.tsv**: Overwrites class, count and status rows. Class is (sigma0(Y)-sigma0(X)) mod 2^32, with sigma0(x)=ROTR7(x) XOR ROTR18(x) XOR (x>>3). Rows are ordered by decreasing count; equal-count rows retain NumPy's ascending class order.

**Console diagnostics**: Prints whether the example pair's modular W11 difference matches the row, its class, number of free bits, reachable classes and VALUE_MAP labels outside the reachable set. A printed False does not stop output generation.

## Failure modes

- The printed pair sanity check can fail while the process exits successfully and writes a fresh table; inspect it explicitly.
- Changing the row changes both the domain and delta. The published rank-seven proof is for the exact archived row, not arbitrary replacements.
- Uppercase or differently formatted class labels may be marked UNSEEN because membership uses exact text, not normalized integers.
- A class count is a count of permitted word values, not complete expanded messages, common-IV solutions, collisions, or a measured attack success rate.
- Malformed rows and missing relative inputs are not handled as a validated schema. The source can raise a parser/index exception or allocate an unexpectedly large domain.
