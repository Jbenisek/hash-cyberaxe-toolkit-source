# Backward demand walk: exact until a nonlinear input differs

Source: `research/tools/profile/backwalk.py`

Public SHA-256: `8028234d38894e901dd1ce9225e7f1e3529fd3b84dbd6845d502f53255e98600`

## Reviewed usage contract

Expand two messages and derive modular A/E demands backward from an assumed equal eight-word terminal state. It prints exact demands only while every input to the nonlinear mixing functions is equal, then stops at the first value-dependent step.

## Source inspection and available execution evidence

static-source-review; eighteen-bounded-cli-cases-and-1352-inverse-row-comparisons-passed.

Two fixed 64-word schedule expansions and at most R backward diagnostic steps. Reaching a compatible legal initial state or satisfying the first value-dependent step is separate work and is not priced by this diagnostic.

## Declared inputs

**CLI and pair**: python profile/backwalk.py PAIRFILE R. The file supplies M1 and M2 followed by sixteen hexadecimal 32-bit words each. No chaining value is read or enforced. Repeated labels overwrite earlier entries. Validate complete legal word arrays and 1<=R<=64 before calling.

**Shared reference module**: Imports indep_sha256_check.py from the parent of the profile directory. The tested source is pinned in the replay kit. Expands each message to 64 words regardless of R.

**Terminal premise**: Initializes all four terminal A differences and four terminal E differences to zero. This is an assumed boundary condition, not a fact established from an input pair or starting state.

## Outputs and interpretation

**Exact row demand**: When old a,b,c,e,f,g differences are all known zero, Delta T2=0 and Delta T1=Delta A_t. It computes Delta d=Delta E_t-Delta A_t and Delta h=Delta A_t-Delta W_t modulo 2^32, placing these at row t-4.

**Stopping message**: Prints VALUE-DEPENDENT and stops when a mixing input is unequal or unknown. It does not solve that nonlinear dependency. A final walk stayed exact message means only this diagnostic reached its loop boundary.

## Failure modes

- Neither a common chosen IV nor the standard IV is imposed. A walk exact to the beginning can demand different initial states on the two sides.
- R=0 and R=-1 silently run no compression step and print that the walk stayed exact. These are not valid positive-step certificates.
- A nonzero nonlinear input difference can sometimes cancel for particular values; the stopping rule does not prove impossibility.
- The printed knot clamps its lower row to zero even though initial A/E coordinates use negative indices. Keep the actual step and row conventions.
- Input length, word range and the full permitted R domain are not validated. Missing keys or excessive steps can fail through indexing rather than a clear validation message.
