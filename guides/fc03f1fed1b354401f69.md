# Row assembler: build a disposable document tree

Source: `research/launch/port/newrow.py`

## Reviewed usage contract

Copy an existing directory into a previously nonexistent output, then invoke filltmpl.py for each template. The bounded usage check uses a small synthetic dummy tree. The tool assembles files; submission and scientific verification are separate processes.

## Source inspection and available execution evidence

static-source-review; disposable-dummy-refill-existing-output-refusal-and-partial-failure-controls-passed.

At least the base-tree copy plus each fill operation. Large or unnecessary inherited files can dominate time and storage. No rollback or complete output-validity certificate is supplied.

## Declared inputs

**CLI**: python newrow.py TEMPLATE_DIR VALUES_JSON ROW_KEY BASE_DIR OUT_DIR [FILE_REL=TEMPLATE_NAME ...]. The template directory must contain each NAME.tmpl and its companion NAME.vals.json. Keep filltmpl.py beside the script.

**Values and destination choice**: For each template name, uses VALUES_JSON[name] when present, otherwise the entire loaded object as the row's slots. An explicit mapping wins; otherwise it writes at the output root if that path exists or the base has other than one immediate subdirectory, and inside that one subdirectory otherwise.

**Trust boundary**: Inputs and destination mappings are trusted. The original performs no containment check against absolute paths or parent traversal. Validate all resolved destinations within the intended scratch tree before use; never accept untrusted mappings or copy a base containing private artifacts.

## Outputs and interpretation

**Copied and refilled tree**: Refuses an already-existing OUT_DIR, then copies the entire base and overwrites mapped files through the filler. Prints each filled relative path and elapsed wall time. Timing is document assembly, not attack cost.

**Intermediate values**: Writes OUT_DIR/.vals_tmp.json for each template and removes it only after successful filling. A failed fill can leave both the copied tree and this temporary values file.

## Failure modes

- A missing mapped parent directory causes filling to fail after the base copy, leaving partial output and .vals_tmp.json; this was reproduced.
- The existing-output guard prevents blindly rerunning into that partial tree. Inspect and recover only the intended scratch output; do not delete broad project paths.
- The entire base is inherited, including stale identifiers, extra artifacts or private data. This source is not a safe publication filter.
- Default single-subdirectory placement depends on base layout. Use reviewed explicit mappings instead of guessing.
- No proof, cost, provenance, JSON schema or cryptographic validity is checked by successful assembly.
