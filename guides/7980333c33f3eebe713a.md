# Transform pass planner: optimize a supplied charge model

Source: `research/levers_1029/pos_r15_xconv/tools/geo.py`

Public SHA-256: `cdd7ebc0e8172a55f0426afe2dab96b441ec843058912d4967fc3a391e1ead50`

## Reviewed usage contract

Compute operation counts for grouped transform passes and choose an ordered pass-width composition with minimum modeled cost. The source contains integer arithmetic only; it does not execute a transform or validate the inherited primitive-operation prices.

## Source inspection and available execution evidence

static-source-review; copied-cli-and-interface-checks-passed; existing-kit-compares-1011-small-composition-candidates.

At most seven predecessor comparisons for each of nl DP entries, plus Python-integer arithmetic and list copying. It allocates a small DP list, not an array of length 2^a. This planning cost is not automatically included in the operation total it returns.

## Declared inputs

**API**: pcost(a,k,l0,cnt,tw1=True) prices one pass. cost(split,a,cnt,tw1=True) sums an ordered width list. runsplit(a,nl,cnt,tw1=True) returns (minimum_cost, split). Validate integer a>=0, 0<=nl<=a, positive cnt, widths 1..7, and valid cumulative layer offsets before calling.

**Inherited table**: COL maps widths 1..7 to fixed (nb,k0,kp) charges; F(cnt)=5+3*floor(cnt/8)+3*(cnt mod 8), and oc(nb)=2*nb+6. These constants are historical premises. Replacing them changes the optimization problem.

**Twiddle term**: When tw1 is true, pcost subtracts 2^l0*((2^k-1)*cnt-3). This term can be negative at small counts; do not assume every subtraction is a saving or transplant an upper-bound argument without checking its sign.

## Outputs and interpretation

**Ordered minimizing split**: The DP considers terminal widths in ascending order and updates only for a strict improvement. Equal-cost candidates retain the first encountered predecessor. The optimum is over this table, its additive recurrence and widths 1..7 only.

**Command-line behavior**: Running geo.py exits successfully without printing anything: it is an importable arithmetic helper, not a search CLI.

## Failure modes

- Domain validation is incomplete. runsplit(3,-1,8) returns (0,[]) instead of rejecting the negative layer count; this was reproduced.
- Unsupported k values can cause a dictionary error; k>a can cause a negative-shift exception. Validate before interpreting the output.
- An optimum for this additive charge table is not proof that no different algorithm or layout is cheaper.
- Finite composition comparisons check the implementation; they do not prove the primitive prices, memory accounting, success law or complete attack charge.
