# Census ranking: suffix labels, duplicate policy and filter order

Source: `research/tools/schedexact/lastdiff_rank.py`

Public SHA-256: `75b769b13cdab5f86cc59d844b9edd355f7d4d5eb74d0e059853b41fb0a7310c`

## Reviewed usage contract

Rank saved census records by a filename/table-derived suffix-length heuristic, not by verified attack work.

## Source inspection and available execution evidence

static-source-review; synthetic-ranking-summary-fallback-and-duplicate-controls-passed; solver-labels-not-reverified.

Linear input parsing plus sorting retained rows. No solver or cryptographic replay.

## Declared inputs

**One or more TSV files**: R, comma-separated words, optional comma-separated kicks, verdict, optional extra fields. Only exact verdict SAT is retained; comments starting # and unparsed headers are skipped.

**Filters and summary**: --min-free and --max-words filter ranking rows. --summary returns counts accumulated before those filters.

## Outputs and interpretation

**Ranking**: lastdiff=max(kicks), else max(words), else -1. core=lastdiff+1; free=R-1-lastdiff. Sort by descending free, ascending word count and descending R. Duplicate records are retained.

**Summary**: Counts by input filename, R and lastdiff; duplicates count repeatedly. It is not a count of unique witnesses, full-state SAT proofs or filtered ranking rows.

## Imports

- Python standard library. Missing input files are reported to stderr and skipped, so inspect diagnostics.

## Worked examples

### Rank a saved census

Working directory: Folder containing lastdiff_rank.py and a validated census.tsv

```text
python lastdiff_rank.py census.tsv --min-free 10 --max-words 8
```

Expected: Filtered ranking with file/R/lastdiff/core/free/nwords/words/kicks/extra columns. No new feasibility result.

### Inspect pre-filter summary counts

Working directory: Same folder

```text
python lastdiff_rank.py census.tsv --summary --min-free 99
```

Expected: All input SAT-labelled group counts still appear, even when the corresponding --min-free 99 ranking would be empty.

## Failure modes

- Fallback to message-word indices cannot prove absence of later expanded-word differences.
- free is not free attack rounds, neutral bits or independent dimensions.
- Duplicate records inflate raw counts if treated as unique cells.
- --summary ignores rank filters by design of the current control flow.
- SAT text is an inherited label, not an imported proof.
