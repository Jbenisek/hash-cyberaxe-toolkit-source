## Reviewed usage contract

The three archived H16-named source files are byte-identical. Compared with the seven-round compact binary edition, they change endpoint fields from 63/17 to 47/17, records from 10 to 8 bytes and default kappa from 14 to 16. The stage-one gate remains 32 planes in both the code constant and the full-width configuration. Directory names do not establish a 16-plane gate. The main circuit remains 45,974 binary operations. Source credit remains jungjipdo’s 6ae36351 for the pivot adder and masked walk, with 0a9640ed / 3356413f credited for surrounding implementation. Finite tests do not certify a surrounding package or success model.

## Declared inputs

**Actual target and message**: ROUNDS=7, UNIT=1470, standard IV, counter 0, block length 64 and flags 11. The message is 32 zero bytes followed by little-endian 256-bit x. Seven-round source identities and finite digest fixtures are checked independently of prior editions.

**Full-adder primitive and attribution**: Choose a pivot p so x and y have equal polarity. With u=x XOR p and v=y XOR p, sum=u XOR y and carry=(u AND v) XOR p. Polarity-aware AND/OR emission yields five binary operations for three variable inputs.

**Masked-walk interpretation**: The circuit stores g(x)=f(x) XOR q, with q derived from output polarities. Fixed q preserves equality of outputs exactly but changes trajectories. f_scalar returns the unmasked digest. A matching mask does not transfer a random-mapping or probability premise.

**Artificial supplied budget**: The fixture supplies Tp=22, B=10^35, kappa=14, 90,653 records, 800 declared registers and slice size 2^48. The default kappa is 16, not the fixture’s 14. The numerical budget helper is replaced by a constant; no optimized budget or probability is inferred.

**Organizer experiment meanings**: bsrho-n18 combines one reduced masked target attempt with a keyed BLAKE2b ideal-control attempt. T1 instead iterates unmasked f with a fresh first message half. proj-k0-w256 unmasks stored values before seven 21-bit projections; a w0 repeat is not a full-digest collision. Trial modulo 3 selects one of three input families.

**Safe example boundary**: Use the compiler-only command below in a disposable directory with the pinned download. It performs no walk or probability optimization. --selftest includes actual collision attempts; --stats runs campaigns; --ledger and --loss select/evaluate numerical plans. --gen-c emits source but does not compile it. Original search routes and launch scripts were not run.

## Outputs and interpretation

**Local Boolean identity**: All 512 bit/polarity/constant-substitution cases pass on this exact source. The 64 distinct-variable cases emit 5 abstract gates. Wrong-sum and wrong-carry controls are rejected throughout. This establishes the local adder identity, not hardware primitive pricing or complete-generator correctness.

**Own-source complete-hash and allocation fixtures**: 256 complete-message lanes match the separately pinned reference, with two known answers. Two masked steps, 18/20-bit fixtures and seven packed values pass. All 45,974 allocated instructions are structurally checked in 23 chunks, with 771 registers. Packed recovery uses 1,540 operations; changed-register and changed-operator controls are rejected.

**Exact supplied-budget ledger**: N=15455334169140809114955300796053788071099 word operations for the artificial supplied budget, reference unit 1470. Main 45,974 + filter 34 + outer-loop 3 = body 46,011. Not a default, optimized, accepted or success-certified score.

**Instruction basis and code-size boundary**: Eight large recovery-mask immediates require at least 248 additional bytes under the declared five/36-byte encoding. Search memory 1,048,508 becomes at least 1,048,756: 180 bytes over one MiB. This lower bound is not a repaired layout or adjudication.

**Declared memory and preprocessing**: Declared code 281,300 bytes; 90,653 records of 8 bytes; counters/copy 16,384 bytes; registers 25,600 bytes. Setup/search phases 400,452 / 1,048,508 before omitted immediates. Setup uses factor 200 times (2 × 92,876 generator primitives + 45,974 instructions), plus the fixed allowance. These are source-model charges, not measured host instructions or RSS.

**Record fields and recovery**: A 47-bit endpoint key and 17-bit trail ID occupy 8 bytes. The conservative 90,911-start envelope fits 131,072 trail values. Shorter keys increase the possibility of stored-key matches without full-digest equality; a larger table is not automatically a success-rate gain. Six artificial one-batch controls pass. Recovery is charged twice at 1,540+64 operations per batch plus 600.

**Domain and cache boundaries**: Four nonnegative record roundtrips and two upper-overflow controls pass. Negative packed fields are accepted and can alias maximal unsigned fields; internal IDs are nonnegative. The B cache omits Sb. A synthetic oracle demonstrates stale reuse when Sb changes, not a failure of the one fixed archived default. Validate inputs and isolate the cache for parameter sweeps.

**Statistics and dispatch**: [5,5,5,7] gives two duplicate entries but three equal pairs. Projection expressions keep 21 bits where comments say 22. Mocked dispatch ignores target metadata, retains repeated/negative trial IDs and rejects unknown experiment names. A synthetic Halt preserves prior counters. These interface observations are not a schema guarantee or complete work count.

**Numerical-model boundary**: The retained numerical helper contains the seven-round tiny-loss expression -120+(exp(2)-1)hh. No numerical helper, optimizer, success theorem or C/wasm execution was replayed. The unchanged kernel does not justify reusing another edition’s endpoint-key loss or price.

**Executable stage-one distinction**: STAGE1_PLANES=32 and CFG[256].s1=32. An all-zero-lane control plus 32 one-bit perturbations confirms that each of the first 32 planes can reject the selected lane. A hypothetical 16-plane call accepts perturbations in planes 16–31. These 33 synthetic cases establish the interface distinction, not a measured or proved target pass rate.

## Failure modes

- Include the demonstrated minimum 248-byte immediate correction; the declared layout alone is incomplete.
- The supplied-budget numerator is not the default, optimized, accepted or success-certified price.
- Do not transfer earlier-round adjudications, probability laws or replay kits to this seven-round identity.
- Read executed constants rather than stale round or endpoint-field comments.
- Compare primitive bases before comparing operation counts.
- Validate negative fields; reset the budget cache when varying omitted parameters such as Sb.
- Unmask outputs before digest comparison and distinguish partial-output repeats from full collisions.
- Preserved output equality under a fixed mask does not prove a random-walk success law.
- Do not read H16 in a directory name as proof that the full-width gate tests 16 planes; this source tests 32.
