# Poseidon toy roots: enumerate exact small-field fractions

Source: `research/poseidon/pkg_r7_paper/out_draft/experiments/toy_root_fraction.py`

Public SHA-256: `6f4b8b3a39f962c4452b9df5b7b90d860233b1f65051fb17a3be0b790ecbd280`

## Reviewed usage contract

Diagnostic for a root-existence premise behind a Poseidon line construction. It builds two Poseidon-like functions with seeded random MDS matrices and constants over a small prime field, then counts exactly which centres c have a nonzero displacement s with F(c+s)=F(c-s). These are not the deployed Orchard constants or its 255-bit field, so exact toy fractions do not establish H_root for that target.

## Source inspection and available execution evidence

static-source-review; instrumented helper tests on tiny fields and mocked main; no default 8,017-element campaign.

The default main computes both toys once per request, even for zero output rows. Each exact_fraction call checks 8,017 centres with up to 4,008 displacement comparisons per centre (32,132,136 comparisons before short-circuit effects); it also makes slices. There are four such counters across the two toys and their controls. Function-table construction, 20 line checks per toy, degree checks and random-table generation add work. Output serialization grows with trial count. This is not an attack-cost ledger or an estimate of the deployed-field root rate.

## Declared inputs

**JSON request**: Only trials and each row’s trial identifier are used. schema_version, target_profile, event and per-trial seed are not validated or used. An empty trials list still performs the full toy computations before returning no rows. A missing trials key fails only after that work.

**Fixed toy specification**: SEED is toy-root-fraction-v1. The field is the first prime greater than 8000 congruent to 2 modulo 5: 8017. PATTERNS are L=3/FPF and L=4/FFPF after the first two full layers; formal degrees are 125 and 625. The same fixed random-number stream selects an MDS matrix, constants, capacity, line checks and random-table control. Request seeds do not select new toys.

**Import hazard**: The last source line calls main() unconditionally. Importing or using runpy on the unmodified file starts the experiment and reads stdin. There is no small-size CLI flag. Do not use an import as an installation check.

## Outputs and interpretation

**One shared observation object**: Every requested row preserves its trial identifier and receives the same observations. Both message fields are null. toy_p is 8017; for each L the output includes degree D, line_ok, degree_ok, centres_with_root, centres_total and control_with_root. More request rows do not mean more independent experiments.

**Exact centre count**: exact_fraction returns an integer count, not a floating-point fraction. Divide centres_with_root by centres_total=8017 to obtain the exact rational fraction for that one seeded toy. It checks every centre and the nonzero displacements up to sign. The control is another fixed finite table and is also counted exactly.

**Different kinds of checks**: line_ok tests 20 nonzero line parameters from the fixed RNG stream, not every parameter. degree_ok checks finite differences of orders D and D+1; the composition gives the necessary degree upper bound, and D<p. Neither flag changes the target into deployed Orchard Poseidon.

**Bounded publication evidence**: The audit removed only the final unconditional main call in an in-memory instrumented copy. The centre counter matched direct enumeration for 34 tiny tables; four fixed line constructions at primes 7 and 17 matched all 48 line parameters. No degree conclusion is claimed for these fields smaller than the formal degree. Mocked main verifies ignored request metadata, repeated observations, null outputs and the empty/missing-trials cost trap. The default seeded 8,017-element campaign was not run.

## Failure modes

- Do not import or runpy the original script as a cheap smoke test: main is unconditional.
- Identical observations under multiple caller IDs are duplicated output, not independent statistical samples.
- Neither the toy function nor the random-table control uses deployed Orchard constants. Do not extrapolate the exact 8,017-centre count into a proved large-field probability.
- Schema, target, event and trial seeds are ignored. Parser acceptance does not establish that a requested cryptographic event was tested.
- The public audit did not execute the default seeded campaign. Its smaller helper examples and mocked interface do not certify the default stored or prospective counts.
- The MDS-generation loop retries until all required minors are nonzero; the source provides no explicit retry cap.
