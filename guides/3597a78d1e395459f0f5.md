# Board-pair generator: signed characteristics, middle pins and seed exclusion

Source: `research/game/climber/guided/boardpairs/gen_boardpair.py`

Public SHA-256: `19573f5e4f69f24066d12371bfd3c642bf342635af07eeadcb5576c777daff29`

## Reviewed usage contract

Generate one SAT instance around an existing reduced-step SHA-256 collision, preserving its own signed characteristic, optionally releasing one row-cell and pinning a band of concrete internal states. The SELF path uses a shared chosen chaining value, not the standard SHA-256 IV. This is an encoder CLI, not a solver. The complete teaching kit supplies the reviewed sibling imports, two seeds and a bounded replay wrapper: downloads/boardpair-teaching.zip.

## Source inspection and available execution evidence

static-source-review; bounded-replay-passed.

Under the documented defaults, seed profiling performs two N-step computations; encoding constructs two N-step bit-vector circuits and their message schedules. Circuit construction and storage scale linearly in N at fixed 32-bit width and fixed row formatting. A band of B mapped rows appends exactly 128B unit clauses. real appends one 1536-literal seed-exclusion clause (512 CV literals plus 1024 message literals). The whole CNF is retained in memory during encoding and read back as text for rewriting. The linked report records exact clause/variable counts and observed generation times for SELF with band 16..19, no release, ctl/real at 37/38 steps. These counts do not price solving or other parameters. Nondefault environment modes can add significant work. There is no timeout, memory budget or SAT-search limit because no SAT search is started.

## Declared inputs

**Eight positional arguments**: SEEDWIT CHARSRC N BAND_START BAND_WIDTH RELEASE MODE OUTBASE, in exactly that order. The code unpacks argv[1:9]; fewer arguments fail, and trailing arguments are ignored. There is no --help or named-option mode.

**SEEDWIT**: JSON with cv as eight hexadecimal word strings, and M1 and M2 as sixteen hexadecimal word strings each. Supply canonical 32-bit words. The loader does not validate lengths or word ranges, and ignores the witness's R/n metadata; CLI N controls the seed profile. The seed must pass the imported profiler's nontrivial final-state-equality assertion at N.

**CHARSRC and N**: SELF derives 32-bit MSB-first signed A/E/W rows from the seed, with equal-but-free chaining rows -4 through -1. Otherwise CHARSRC is an existing characteristic file read by a regex parser, not a general XML parser. Its name="n" value and rows control the encoder; the generator does not check that its n agrees with CLI N. Use matching n, 32-bit rows and shared-CV constraints. The reviewed examples use N=38 or N=37, with SHA-256 constants starting at K[0].

**Band and release**: For each mapped state index t in [BAND_START,BAND_START+BAND_WIDTH), append unit clauses fixing A1,A2,E1,E2 to the seed values. Unmapped rows are silently skipped; nonpositive widths add no pins. RELEASE is none, A<t>, E<t>, W<t> or AE<t>; matching character cells become question marks. Releasing a shape cell does not remove separately appended band pins. A missing row or missing W cell is silently unchanged.

**MODE**: Exactly real adds one clause excluding the complete ordered seed assignment of both CVs and both messages. ctl adds none; any other spelling also silently adds none. Exclusion does not fix the chosen CV, exclude the swapped seed, or guarantee a better characteristic or attack.

**Encoder environment**: The generator sets SIGNED=1 before import, but inherits the remaining sha_cnf controls. For the documented 32-bit model use defaults: WBITS=32, BITORDER=msb, CHAINREV=0, KOFF=0, EXTRAW=0, DIFFVARS=0, SCHED_ONLY=0, XORMODE=0, XOR3=0, SYMBREAK=0, NEAR_ENC=seq, NEAR_OUTS=0, and unset/empty MODDIFF, NEAR_K and REQUIRE_DIFF. In particular SCHED_ONLY removes the compression circuit, WBITS changes the width, and XORMODE produces native XOR lines rather than plain CNF. The XML w option does not override the encoder's environment width.

**OUTBASE**: An output basename in an already existing writable directory. Use a new basename: .xml, .cnf and .map are opened for writing and existing files are overwritten without confirmation.

## Outputs and interpretation

**OUTBASE.xml, OUTBASE.cnf, OUTBASE.map**: The XML contains the derived/read shape after release; it does not contain the later middle-pin units or seed-exclusion clause. The DIMACS-like instance contains those extra clauses and a rewritten clause count. The JSON map records variable IDs, width where nondefault, and the string chaining=sfs; that label alone does not enforce shared CVs. Equality is supplied by the characteristic rows.

**Standard output**: On successful encoding, prints OK pins=U extra_clauses=E. U counts appended unit clauses; E=U+1 for real and U otherwise. This is an encoding report, not SAT, a witness, a probability or a verified collision.

**Startup and side effects**: Startup prepends ../kit to Python's import path and sets SIGNED in this process's environment. Main reads seed/shape and generated map/CNF, suppresses encoder stdout through the null device, then rewrites the CNF. No solver, child process or remote service is invoked. Failure can leave partial or mismatched output files; stdout restoration around encode is not protected by finally. Use -B to suppress import bytecode-cache writes.


Working directory: The extracted boardpair-kit directory

## Failure modes

- A single gen_boardpair.py download still lacks its relative dependencies. Use the complete teaching ZIP and preserve the directory layout.
- Contrary to the generator docstring, apply_release does not protect the last four rows. Releasing final A/E cells can remove final-state-equality requirements. Keep those rows equal, and independently verify every decoded pair.
- The shared chosen-CV model follows from equal chaining rows in SELF, not the string sfs. An external characteristic that frees chaining differences changes the model. This is not a standard-IV full SHA-256 attack.
- The characteristic parser requires its specific double-quoted n-option pattern and row syntax. It silently ignores unrecognized row text, and the generator does not reconcile CLI N with file n.
- A release token can silently do nothing if its row/cell is absent; malformed tokens can raise. Band pins can still fix values in a released row, so inspect the actual CNF/map rather than inferring freedom from XML alone.
- Any MODE other than exactly real behaves like ctl. The exclusion clause forbids only one complete ordered assignment, not every seed-equivalent solution.
- Do not use Python -O: the seed-collision assertion is a safety check. The loader does not validate canonical word lengths/ranges or explicit CLI step bounds.
- Nondefault inherited encoder variables can change the width, constants, chaining interpretation, collision requirement or output format. In particular schedule-only SAT is not a compression witness.
- Encoding success is not evidence of satisfiability. The decoder prints diagnostics without enforcing them, and the separate independent checker prints INDEP NOT VERIFIED without a dedicated nonzero failure exit. Inspect the actual verification verdict, both CVs, message inequality and target parameters.
