# Sign-variant writer: W-only mirrors and explicit state relaxations

Source: `research/tools/profile/mirror.py`

Public SHA-256: `2587da04dcd1bb6012fd43b7397d9222e2fa3ead3ea0977473ae507536e53c6d`

## Reviewed usage contract

Generate explicitly labeled text variants for a later experiment without assuming the mirror label transforms every state constraint.

## Source inspection and available execution evidence

static-source-review; eight-disposable-CLI-cases-and-36-output-variant-checks-passed; no-solver-run.

Text processing plus file output, exponential in the optional word-list length. No claim about the cost or feasibility of solving any generated variant.

## Declared inputs

**BASE.xml OUTDIR**: A text-row characteristic and a fresh output directory. The regex expects rows with A, E and W on one line and lowercase u/n signs.

**Optional comma-separated words**: Enumerates all subset flips of the supplied word list. Intended for distinct input indices 0..15; the source does not enforce that complete contract.

**SCHED / STATEX environment**: SCHED=1 frees all A/E rows; STATEX=1 changes signed A/E u/n to x. SCHED dominates when both are set.

## Outputs and interpretation

**Default variants**: base, mirror, xexp and flipK for each signed input word, plus list.txt. The mirror changes W u/n only; xexp frees W16+ orientations to x.

**Explicit subset mode**: xexp and every nonempty listed subset; default base/mirror entries are absent. Two distinct indices produce four variants.

## Worked examples

### Create text variants in a new scratch directory

Working directory: Scratch folder containing mirror.py and a reviewed base.xml

```text
python mirror.py base.xml sign_variants_scratch
```

Expected: Creates list.txt and 3+N XML-like files, where N is the number of signed input-word rows recognized by the regex. This does not solve or certify them.

## Example runs and tests

Eight disposable CLI cases and 36 generated text variants. No solver, schedule feasibility, collision, sign-space rank or runtime-gain claim. Default W-only mirror is not a full pair-swap equivalence when asymmetric signed A/E pins remain. The runtime report identifies tested bytes, not every function or mode in the tool.

## Failure modes

- Existing named outputs are overwritten; choose a fresh scratch directory.
- Default W-only mirror leaves asymmetric signed A/E pins unchanged.
- SCHED/STATEX relax the state problem; partial flips also relax later W orientations.
- Unsupported row layouts may be left unchanged by the regex.
- Uppercase signs and invalid/duplicate word indices are not robustly validated.
