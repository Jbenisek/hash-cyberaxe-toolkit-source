# Schedule-support templates: select free words and state bands

Source: `research/game/climber/guided/minsup/mk_tap.py`

Public SHA-256: `f8547f0ea192e61d47c5ed50e287276d0b80e17a53a05dd03c853b43482222e9`

## Reviewed usage contract

Generate a width-32 characteristic template for two reduced-step SHA-256 trajectories. It permits selected schedule words and a chosen band of state rows to vary. This is a description of constraints, not a solved differential or a collision generator.

## Source inspection and available execution evidence

static-source-review; bounded-template-fixtures-passed; no SAT solving or encoding-equivalence proof.

For a valid N, emits N+4 fixed-width state rows and N schedule fields: linear text-generation work and storage in N. The bounded tests use four tiny fixtures and two rejected-input controls. No search budget or attack cost follows from generating XML.

## Declared inputs

**Invocation**: python -B mk_tap.py OUT N DIFFW STATEFREE. OUT is an output path; N an integer step count; DIFFW a comma-separated nonempty list of integer W indices; STATEFREE an inclusive nonnegative lo-hi pair. There is no argparse, help mode or main guard: importing executes positional parsing and may write a file.

**Supported example domain**: Use 4<=N<=64, 0<=W index<N and 0<=lo<=hi<N. The source does not enforce these bounds. Negative/out-of-range W indices can be ignored silently; an inverted state interval produces no free state rows. Malformed integer syntax or missing arguments raises an exception.

**Three distinct meanings**: A question mark leaves a bit unconstrained between the two copies; it does not force a difference. A dash forces equality but does not choose its value. Selected DIFFW rows become all question marks, so the template alone still permits equal messages. A separate nontriviality condition is required for a collision search.

**State constraints**: Initial A/E rows -4..-1 are equal across sides. For t=0..N-1, state A/E bits are free only if lo<=t<=hi AND t<N-4; all other state rows are equal. Thus the last four state rows remain equal even when STATEFREE includes them. Early equal-state rows outside the chosen band are substantive constraints, not neutral formatting.

## Outputs and interpretation

**XML-like characteristic text**: Writes options f=sha2, n=N, w=32 and N+4 A/E rows. Every row string is 32 characters, with W fields for t>=0. Both A and E use the same free/equal mask. The file ends with a newline and successful execution prints nothing.

**Filesystem effects**: Overwrites OUT without confirmation; its parent directory must already exist. No subprocess, solver, network operation or additional output file is part of this script.

**What a later verdict would mean**: An UNSAT result for an encoded template only closes that constrained instance with its added nontriviality/model settings. It is not a universal impossibility for those message-support positions: the chosen early equal-state requirements may be the obstruction.

## Imports

- Python standard library sys only. No encoder or solver is required to generate the text.
- A later search needs a separately checked pair encoder, exact initial-state convention, nontriviality rule, solver and independent witness verifier. The generator supplies none of these automatically.

## Worked examples

### Generate a 37-step support template

Working directory: A disposable directory containing this exact source file

```text
python -B mk_tap.py example.xml 37 16,19,20 16-32
```

Expected: Writes example.xml with 41 A/E rows. State rows 16 through 32 are free; 33 through 36 and all earlier rows are equal. W16,W19,W20 are free; other schedule rows are equal. This is not a claim that those three words differ or that the instance is satisfiable.

### Observe final-state protection

Working directory: The same disposable directory; protected.xml will be overwritten if it exists

```text
python -B mk_tap.py protected.xml 39 8,12 0-38
```

Expected: 43 A/E rows. State rows 0 through 34 are free, while rows 35 through 38 remain equal despite the requested interval. Initial CV rows remain equal, not pinned to the standard IV.

## Failure modes

- Do not interpret the DIFFW name as a forced-difference constraint.
- Do not overlook equal-state requirements outside STATEFREE; these can create artificial negative results.
- The source overwrites its target and executes on import.
- Malformed or out-of-range input is not consistently rejected; validate parameters before execution.
- Initial equal state is not standard-IV state; keep compression model and feed-forward conventions explicit.
- No signed u/n bits, concrete values, seed exclusions or proof objects are produced.
