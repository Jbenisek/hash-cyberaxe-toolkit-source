# Schedule scan driver: query identity, restart rules and cache limits

Source: `research/game/climber/guided/scan40_topslide/scan_driver.py`

Public SHA-256: `67ec37d0470e8677bf54f4addaefe4e2dd2720a55a43d780946b4e8e8db6f9fa`

## Reviewed usage contract

A historical target-first driver that enumerates nearby allowed-support schedule queries, shards them, calibrates a conflict budget, invokes a solver and records or infers labels. Its ordering, cache and result rules are part of the experimental model. This guide documents the pinned edition without starting the historical launcher.

## Source inspection and available execution evidence

static-source-review; extracted-query-and-driver-fixtures-passed; no encoder, solver or campaign execution.

The portable twelve-case suite is finite and launches no solver. Real campaign cost is not bounded by the documented neighbour count: query enumeration, repeated encoding, calibration, retries, solver caps and cache state all matter. Historical elapsed seconds are not contest operation counts.

## Declared inputs

**Target JSON**: Each target has name, words, kicks and optional R (default 40). words must be nonempty because the smallest word becomes the required difference. W union K is an allowed support; only that smallest message word is forced to differ. This is not the problem requiring every listed word to differ.

**Query family**: Normal generation considers R and min(R+1,45), with zero, one and two add/move edits to kicks in 16..R-2. The old header says 41 but code uses 45; targets above 45 also generate 45. --self-only retains kicks through R-1 and uses only the target's own R. Invalid words, rounds and shard settings are not comprehensively validated.

**Priority and identity**: Queries are deduplicated by (R,W,K) while each target is visited, then sorted by edit distance, target order and R. An earlier neighbour can suppress a later exact target. This means the sort does not always give every target its own distance-zero query.

**Original dependencies and settings**: Imports sibling sched_scan.py, which imports kit/sha_cnf.py. The sibling enables schedule-only mode and preserves any existing WBITS value rather than always forcing 32. Exact dependency versions, effective environment and cached base identities must be bound together. The portable lesson supplies stand-ins instead of these dependencies.

**Budget and resume**: --shard i/N selects a modulo slice; --minutes limits elapsed time; --l0sec sets the calibration target; --ladder supplies multipliers; --retry retries seeds. Stored census rows whose label is anything other than UNDECIDED are treated as done. The resume key lacks encoder and environment hashes, so only a validated same-model ledger is suitable.

## Outputs and interpretation

**Historical artifacts**: The original appends census_i.tsv, creates or reuses base_Rn.cnf beside the script and writes per-query temporary CNF files. Never run the original in a shared live research directory merely to inspect its interface. The teaching fixtures confine all writes to fresh temporary directories.

**Ledger rows**: Twelve fields: R, words, kicks, verdict, ladder level, elapsed seconds, how, target, conflicts, decisions, propagations and restarts. Interim #u lines are comments. Pruned rows can repeat the preceding solver's statistics; those numbers are not measurements of a second solve.

**Verdict boundary**: The driver parses s SATISFIABLE or s UNSATISFIABLE text without requiring a matching exit code or independently checking a model or certificate. Calibration must return UNSAT and a nonzero conflict count. Timeout is undecided, not a proof.

**Bounded replay**: Twelve fixtures extract five unchanged function definitions from the pinned source. Stand-in encoder, solver, clock and confined I/O test control flow. No original module import, SHA formula generation, real solver, server or research job is part of this replay.

## Failure modes

- A cached base_Rn.cnf is reused without checking its encoder/environment identity against freshly generated literal maps; a fixture demonstrates incompatible header and variable numbers.
- Resume accepts an arbitrary non-UNDECIDED label such as PENDING; its text key also assumes canonical index formatting.
- SAT label text may be accepted even with an error return code. Verify numerical witnesses or certificates independently.
- Required-support and allowed-support problems have different implications; keep the required word and base formula fixed before using the pruning rules.
- Pruned-row statistics may be stale, so summing them as independent solver work overcounts.
- Normal and self-only modes disagree on the final kick. The current round cap differs from the header.
- Historical source or dependency changes do not inherit this digest-bound replay result. The tests do not certify encoder correctness, historical campaign completeness or attack probability.
