# BLAKE3 fixed-prefix stack: smaller columns, compact tables and checkpoint recovery

Source: `research/blake3_r3/stack1020/pkg/blake3/experiments/bsrho.py`

Public SHA-256: `65d9b1537f1ac8b5a2a8807a93c7d3179c87a0973e69b5d48a3341b012440411`

## Reviewed usage contract

This three-round implementation combines a fixed public message prefix with three-addend carry columns, a compact endpoint table, a two-stage distinguished-point test and checkpoint recovery. These choices interact through storage and work budgets; their benefits cannot be inferred from gate count alone. The source credits pivot addition and the masked walk to 6ae36351 and column templates 0/1 to 10ce9f59.

## Source inspection and available execution evidence

static-source-review; Finite message/allocation checks, 7,680 local column cases, dictionary and synthetic recovery controls, fixture ledger; no original search or selection scan.

One finite circuit generation/allocation, tested with a ten-second subprocess timeout. Does not run prefix selection, numerical planning, statistics or a collision search.

## Declared inputs

**Target and fixed prefix**: Three-round BLAKE3, one 64-byte block, standard IV, counter 0, flags 11. The first eight little-endian words are 80000000, 00000000, 80000000, 00000000, 70000000, 00000000, 00000000, 00000000; the last eight encode x. KEY is a public message prefix, not a secret or a changed IV. Unit=638. A stale scalar comment mentioning seven rounds does not override ROUNDS=3.

**Column generator**: Where all three 32-bit addends are variable, one carry-pair ripple replaces two ordinary additions. At each interior bit it compares six operand orders and three templates, retaining the fewest newly built gates. Four stored polarity-specific column circuits supplement the two templates. This local greedy choice is not a global minimum-circuit proof.

**Search stages**: The walk is g(x)=f(x) XOR q. Every batch first tests 13 stored planes; passing batches test the remaining 19. The pass counter has its own budget. The full-width plan uses a 90-bit window after the 32-bit stage and supports checkpoint recovery. Only 18 and 256 are configured search-plan widths, although a 20-bit circuit can still be generated.

**Declared table model**: A quotient filter stores a key remainder, 17-bit trail ID and three metadata bits in seven-byte slots. The home slot supplies implicit quotient bits. The Python QF uses five lists as a semantic implementation; those Python objects are not a seven-byte-per-slot memory measurement.

**Safe recipe and expensive entry points**: The compiler-only recipe below neither searches nor selects a prefix. --selftest runs actual reduced collision attempts and other extensive checks; --choose-key runs coordinate descent; --ledger and --loss invoke the numerical planner. They are not part of this finite replay.

## Outputs and interpretation

**Fixed-prefix arithmetic**: Fresh checks match 256 complete messages to the independent pinned BLAKE3 reference, including two reference known answers, two fixed masked-walk steps, reduced-width fixtures and seven packed recovery lanes. All 16,546 allocated instructions are checked across nine chunks; two mutation controls fail as intended. Register extent=773, with no shared/dead gates for this source and prefix.

**Exhaustive local column cases**: All 6,144 variable-input cases and 1,536 constant-carry cases pass, covering the three template choices, stored polarities, sum/carry semantics and terminal carry omission. All 7,680 wrong-sum controls are rejected. This proves the tested local Boolean identities, not the complete hash function, target-machine cost model or success law.

**Quotient-filter controls**: Tables with 37, 64 and 101 slots agree with a dictionary through 36, 63 and 100 insertions, respectively, plus 100 queries each. The checks cover wraparound-oriented keys, reject a full-table insertion and detect corrupted trail values. They are finite semantic tests, not a universal probe-count or packed-memory proof.

**Two-stage gate controls**: Four synthetic cases distinguish an early rejection, full pass, later rejection and exhausted passing budget. A later rejection still increments the passing-batch count, so it is not free. The declared work is 14 operations every batch plus 21 for each counted passing batch.

**Checkpoint recovery controls**: Twenty artificial graph cases cover equal and unequal trail lengths, one trail starting on another, different endpoints and the length cap, with checkpoint counts 1, 2, 3 and 8. Returned pairs are checked against the artificial map. These are not hash-collision witnesses or random-map success measurements.

**Declared layout and fixture ledger**: The declared code region is 134,062 bytes, endpoint capacity 124,633, and setup/search phases 249,418/1,048,516 bytes. The formula uses 800 registers and 32 bytes of prefix advice. Exact summation was checked with artificial B=10^35 and Tp=1500; that fixture is not the default attack price. Its ledger includes checkpoint recovery, passing batches and the declared 12,658,758,600-operation prefix-choice allowance.

**Preprocessing is part of the story**: The generator records 245,538 primitive calls in one pass, including dry column choices; the ledger charges two passes plus emitted instructions. The source describes 241 prefix evaluations, but this audit did not rerun that historical selection or certify its declared allowance. No new C build, retained-wasm comparison or native memory measurement is claimed.

**Probability remains separate**: The full-width loss helper hardcodes its domain and uses floating numerical calculations. Its B cache omits the slice parameter Sb. Do not transfer another edition’s probability proof, call a reduced-width plan a validated full-width model, or turn these finite implementation controls into a complete success certificate.

## Failure modes

- This is a selected-prefix message family, not the earlier zero-prefix family.
- Do not mistake Python list memory for the declared packed quotient-filter layout.
- The stage-1 passing count includes batches later rejected by the rest of the test.
- The fixture ledger is exact arithmetic under supplied parameters, not a publishable default attack score.
- Prefix-selection cost and two generator passes must not disappear from the accounting.
- A local column proof or a synthetic recovery pair does not establish full-width collision success.
- The existing bsel generator ZIP covers a different source and does not replay this edition.
