## Reviewed usage contract

Core library for characteristic parsing, 32-bit A/E arithmetic, real message expansion, common-CV reconstruction, proposal sampling and threaded loops. The linked October 29 baseline report covers this exact compiled edition, not every parser input or algorithmic mode.

## Source inspection and available execution evidence

static-source-review; previous hash-pinned baseline build and checks; not all APIs or input modes.

Thread default is six; explicit settings are clamped to 1..64. Set --threads 1 for bounded examples. Constrained variable rejection can attempt 2^34 candidates before exit 3. The fixed checks and rejection work are additional to a requested sample count.

## Declared inputs

**Model and coordinates**: TLModel contains the characteristic, published messages/CV, anchor, E-driven rows and variable definitions. TLCoord supplies x-member base words and driven E values. Word arithmetic is modulo 2^32.

**Symbols and relations**: '='/'-' require equality; 0/1 also fix x; n/u orient a differing bit; x permits either sign; ? is unrestricted. A plus relation is derived only from matching plus positions in adjacent rows. List paths are relative to the process directory.

## Outputs and interpretation

**Consistency return**: tl_build reconstructs a common CV and returns whether y reproduces its anchored rows. A true return is a consistency check, not a collision. tl_state_eq compares four A and four E rows, not message distinctness or feedforward by itself.

**Incremental precondition**: tl_build_from assumes earlier rows are current and does not recompute low message words or the CV. It is not an interchangeable full rebuild.

**Artifact exception**: hold_from substitutes published expanded words and intentionally creates inconsistent-message experiments. The ordinary real-schedule guarantee does not apply in that artifact mode.

## Failure modes

- Do not promote an anchored-consistency return or row equality to a full digest collision.
- Never use hold_from artifact output as a real-message witness.
- Incremental rebuild requires a correct earlier prefix and cannot silently replace CV/low-word reconstruction.
- Research characteristic/list files are trusted inputs, not a hardened untrusted-data interface.
- Finite deterministic PRNG checks do not prove a sampling law or independence.
