# BLAKE3 halfsearch: construction, toy residual search and counted batches (pkg9/pkg/work/fix4/prev/blake3-r2)

Source: `research/pkg9/pkg/work/fix4/prev/blake3-r2/experiments/halfsearch.py`

Public SHA-256: `31d6f21dbfb71502fe9318a7238794855c89c9ac4fa1ef828cf7919722a8d902`

## Reviewed usage contract

Explore three components of the historical blake3-r2-prefix-v1 experiment for unequal 55-byte and 63-byte messages: an algebraic half-digest construction, a toy residual search and an instrumented 256-bit-word counting model. The construction and toy search measure partial output agreement; the modeled full attack requires its own complete success and cost argument.

## Source inspection and available execution evidence

static-source-review; copied interface controls, three fixed half-digest examples and four counted-batch fixtures; no residual search or selftest sweep.

The half-collision mode constructs one pair per seed without a search. Residual-search performs one diagnostic seven-lane batch plus at most 131072 scalar member trials per seed; no success probability is guaranteed. Its diagnostic pieces counted outer 148 operations/91 loads/21 stores, table word 43/26/5, middle 85/40/9, and batch 142/40/0 on the four fixtures. These omit the whole experiment’s Python/SHAKE costs and do not price a full attack. The self-test also enumerates all class-list entries and rule patterns. There is no whole-request trial-count cap.

## Declared inputs

**JSON request with no command-line arguments**: schema_version must be 1, target_profile must be blake3-r2-prefix-v1, event.kind must be digest-xor-mask, and experiment_id must be half-collision or residual-search. trials contains objects with a trial identifier and a hexadecimal seed decoded by bytes.fromhex. The source checks the event kind but does not validate its mask or value fields.

**Seed and exact source edition**: SHAKE-256 expands the seed to eight little-endian 32-bit words: seven context words and a class index modulo 131072. This file fixes an eight-condition rule, 16 registers, nine resident words and seven 36-bit lanes in a 256-bit word. A different source, cube, rule or machine convention needs a separate contract.

**Self-test CLI is a separate, larger operation**: --selftest N [seed] requires a positive decimal N. It runs N counted contexts but also enumerates the entire class list and all rule-bit patterns, independent of N. Do not assume --selftest 1 is a tiny one-case smoke test; the publication checks did not run this command.

## Outputs and interpretation

**half-collision mode**: One pair of message hex strings per trial, with the caller trial identifier preserved and no observations object. A has 55 bytes, B has 63 bytes and ends in eight zero bytes. Digest words 0,2,5,7 are the constructed equality target. Three fixed examples passed a separate full two-round digest implementation; none of those examples had a full digest collision.

**residual-search mode**: Starts at the seeded class index and visits at most all 131072 members cyclically. It returns the first pair whose digest-word-1 residual has zero low byte, or two nulls after exhaustion. That adds eight tested bits to the 128-bit half event; it is not a full-output equality check. tries and batch_* observations describe this toy run and a separately evaluated diagnostic batch.

**Counting-model observations**: The diagnostic batch evaluates both stages regardless of its stage-A result. Across four tested contexts, stage A counted 37 operations and 10 loads; stage 2 counted 105 operations and 30 loads. The full batch counted 142 operations, 40 loads and zero stores with a peak of 16 modeled registers. These are the file’s 256-bit machine units, not CPU instructions, real time, a measured opening rate or a full run charge.

**Partial last batch**: The class has 131072 members in 18725 seven-lane batches. The last batch contains four distinct remaining members and repeats the final member in three spare lanes. A lane-check count therefore need not be a distinct-trial count.

**Bounded publication evidence**: All nine source copies match one digest. Empty/invalid CLI cases, three fixed constructed pairs and four counted-batch fixtures passed. The separate JavaScript digest comparison also passed two seven-round known answers. The 28 checked lanes include last-batch padding; this is not an all-context proof, statistical sample, residual-search run or exhaustive self-test.

## Imports

- Python 3 standard library: hashlib, json, struct and sys; no local imports. Construction and the source’s complete two-round checker are embedded.
- The publication’s independent digest cross-check used the separate pinned blake3-replay.js and Node.js. That is a test dependency, not a dependency of halfsearch.py.

## Failure modes

- Neither accepted request syntax nor a returned partial match proves that an arbitrary supplied event mask/value holds. Validate the exact intended event independently.
- Both stages are always evaluated by packed_batch; stage_2_entered reports the gate decision, not proof that the diagnostic skipped stage 2. The stage-2 budget comparison is modeled, not an implemented stopping rule for the toy residual search.
- Do not transfer the declared FACTOR=49400000 or full-run budget into a proved success/price statement. Those depend on the external proof’s assumptions and whole-procedure accounting.
- Malformed input raises errors instead of a structured per-trial failure. A bad later seed can prevent the whole response.
- selftest N does more than N small fixtures. Avoid the exhaustive class/rule sweep when only checking installation or examples.
- Counting repeated padding lanes as new members inflates the class size. Four tested batches are not an exhaustive validation of all contexts or register schedules.
- Nine identical file paths are nine distribution locations, not nine independent discoveries or tests.
