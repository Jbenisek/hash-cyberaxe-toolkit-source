# MINE closure meter: replay and rank terminal-state differences

Source: `research/tools/funnel/mine_meter.py`

Public SHA-256: `46ffddad56e5c0efad6498ee40604a1375fce1e7e0e0752cc2751fb9fd8d3465`

## Reviewed usage contract

Scan saved game records with common chaining values, replay their SHA-256 traces and rank the remaining closure mismatches. The script is a workspace-relative table writer, not a portable read-only verifier or a proven attack-probability estimator.

## Source inspection and available execution evidence

static-source-review; eight-bounded-characteristic-and-meter-fixtures-passed; only-disposable-writer-runs.

Linear full-width replay per accepted record plus sorting. The random-mismatch baseline of 128 is descriptive; neither this value nor trailing-zero depth is a calibrated future collision probability.

## Declared inputs

**Workspace-relative inputs**: No CLI arguments. Resolves the research root three directories above its own file, reads sorted game/engine/data/raw/web_*.jsonl and then runs_1031/wcost/owner_shots_1031.jsonl. The final file is opened even when absent, so an incomplete workspace fails.

**Record**: Uses R, shot_id and pair with M1/M2 sixteen hexadecimal words and chain1/chain2 eight hexadecimal words. Initial filtering checks M1 length but not every field. Both chain arrays must compare equal as stored. The intended four-row closure interpretation needs 4<=R<=64.

**Record identity**: The first encountered shot_id reserves the ID before common-chain validation. A rejected different-chain record can suppress a later valid record with that ID. Missing IDs all become None and collapse to one entry.

## Outputs and interpretation

**Current TSV**: Replaces runs_1101/funnel/MINE_METER.tsv. first_row_bits is the A/E XOR popcount at R-4; closure_bits_total sums all four tail rows; bits_over_chance is 128 minus that total. tz_dA_first and tz_dE_first count trailing zeros in modular differences, using 32 for zero.

**History TSV**: Appends every current row again to MINE_METER_HISTORY.tsv with local minute timestamps. Repeating the same run adds repeated observations; this is not an independent-sample log.

**Sorting**: Sorts the complete result tuples, starting with first-row mismatches then total mismatches. Metadata breaks ties. A missing ID tied against a string ID can raise TypeError; heterogeneous metadata can also be incomparable.

## Failure modes

- Do not run the historical script in place just to inspect a source: it overwrites the current table and appends history.
- Duplicate and absent IDs can omit otherwise valid records, including after a rejected different-chain record.
- Mixed missing/string IDs can crash tied-row sorting before the output table is written.
- Common-chain checking compares stored arrays, not normalized numeric values. Inconsistent encodings can reject numerically equal chains.
- A near-zero score is not a completed collision. Zero total means equal working states for the common-CV trace, but distinct messages and the intended target domain still need independent verification.
- Failed or repeated meter runs must not be counted as new independent research trials.
