## Purpose recorded in the source

rule_drat_h8.py -- DRAT proofs for the 54 answers "no solution", and a checker for them.

Written by a reviewing helper agent of this package (lens "construction") as review/construction_drat.py and copied to
tools/rule_drat_h8.py by the agent that applied the review: the paths, the module names, the name of the output
file and this paragraph were changed, nothing else (SHA-256 of the reviewer's file, with LF line ends:
94c64b4e718bde9ca046bb95aaa41d21ad74249761ce298014295e44d4c1a340). Research helper, not submitted.

The count that H1 uses keeps 54 outcomes because solvers answered that the E3 system has no solution that violates
rule A. The package says these answers have no certificate. Here, for each of the 54:

  1. the reviewer's formula (rule_formula3_h8.build, question 2) is solved by cadical in plain mode (no
     preprocessing, so every learned clause follows by unit propagation) with a text DRAT proof;
  2. the proof is checked by a forward checker written here: every added clause must give a conflict by unit
     propagation from its negation (RUP), deletions are ignored (sound for RUP), and the empty clause must be reached;
  3. drat-trim is used as well if it is installed.
