# Compare signed schedule rows at an explicit offset

Source: `research/tools/schedexact/cmp_shift.py`

Public SHA-256: `6e7dc8410b37f23aa09b5eb050643f299e161b4ff580618edad78a6e98cc9ea7`

## Reviewed usage contract

Compare each reference active schedule row against an explicitly shifted row of one or more pair files.

## Source inspection and available execution evidence

static-source-review; zero-and-one-offset-synthetic-CLI-controls-passed; no full characteristic verification.

48-word expansion per supplied pair and bounded string comparisons.

## Declared inputs

**REF.pair REFSHIFT FILE.pair SHIFT ...**: Each file supplies M1/M2 lines of sixteen valid 32-bit hex words. Each file must have a following integer shift. Horizon is hard-coded to 48 words.

## Outputs and interpretation

**Matching reference rows**: Reference row t is compared to row t+SHIFT-REFSHIFT. u=M1 one/M2 zero; n is the reverse. Extra rows are candidate active rows not in the shifted reference support.

**Scope**: A signed profile match does not verify the corresponding state path, legal inputs or any shifted collision.

## Imports

- Python standard library. The module executes its CLI at top level; do not import it as a safe library or assume a --help mode.

## Worked examples

### Use the same-file alignment control

Working directory: Folder with cmp_shift.py and a validated M1/M2 fixture.pair

```text
python cmp_shift.py fixture.pair 0 fixture.pair 0 fixture.pair 1
```

Expected: Offset zero matches every active reference row. The supplied one-bit synthetic fixture does not match all rows at offset one. Neither result is a collision claim.

## Failure modes

- Missing or short M1/M2 lines and malformed argument pairs are not robustly validated.
- Matches outside the 48-word horizon cannot be established.
- Schedule translation does not remove compression-state or round-constant constraints.
- An empty reference support can produce a vacuous zero-of-zero comparison.
