## Reviewed usage contract

Historical rerun launcher moving the free-state start from row 8 to the first listed differing word. This removes one proved model contradiction for eight saved shapes; it does not establish satisfiability, solver correctness or a collision. The source was read completely, not executed.

## Source inspection and available execution evidence

static-source-review; not-replayed-for-publication.

No finite search-cost bound is enforced by this launcher. Reported duration includes polling latency and is not a clean solver-performance measurement. The safe teaching replay is finite and solver-free.

## Declared inputs

**Saved shapes**: Reads shapes.tsv from the script directory: id, R, comma-separated base words, comma-separated expanded kick rows. The code takes the first base word. The eleven saved rows are sorted; a new unsorted list need not put its minimum first.

**Model**: Calls mk_tap with allowed W rows words+kicks, free state first-word..R-5, equal final four A/E rows and common free initial chaining values. REQUIRE_DIFF demands the first word differ. A question mark only permits a difference; it does not require every selected word to differ.

## Outputs and interpretation

**Files and concurrency**: Appends to RESULTS.tsv, overwrites per-shape XML/CNF/map/out/chk files, and starts every input row as a background lane without an overall worker cap or solver timeout.

**Timing and verdicts**: Checks solver lifetime around sleep 1800. A finished process may be reported almost 30 minutes late; recorded elapsed minutes include that delay. Exit code 10 becomes SAT, 20 UNSAT, other codes ERR. SAT_CHECKFAIL means the decoder output lacked the literal equal-output success text; that text alone is not an independent collision certificate.

## Failure modes

- Do not run it from a publication download: it launches uncapped searches and overwrites per-lane files.
- First listed word is not generally min(words); validate ordering for new input.
- Removing the early-state contradiction does not establish that another contradiction is absent.
- A decoder summary is not a checked CNF assignment, message-domain validation or independent full-digest replay.
- Repeated runs append mixed historical rows; retain source version, run identity and exact model with any verdict.
