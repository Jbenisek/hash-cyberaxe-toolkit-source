## Reviewed usage contract

Summarize overlap between saved scan40 census rows and an outside screen CSV using only (steps, sorted words, sorted kicks). It does not reconcile all experimental constraints or verify SAT witnesses and UNSAT proofs.

## Source inspection and available execution evidence

static-source-review; ten-synthetic-interface-controls-passed; no-historical-recount-or-solver.

Linear parsing of saved rows plus small per-support sorting and dictionary/set operations. Ten finite fixture processes have ten-second limits. This is not a cryptanalytic attack price.

## Declared inputs

**Local census rows**: Relative glob ../../game/climber/guided/scan40/census_*.tsv. First four columns are decimal steps, comma-separated words, comma-separated kicks, status. Rows with fewer than four columns or nondigit steps are skipped. Only SAT and UNSAT update the local dictionary.

**Outside screen CSV**: Relative file unsat_1027/unsat_data_2026-10-27/screen.csv requires steps, words, kicks and status headers. Words and kicks use whitespace-separated decimal integers. Weight-cap and other fields are not included in the key.

**Working directory**: Both input locations are relative to the process working directory, not the script. Use the supplied wrapper to build disposable fixture directories. The original executes on import and has no CLI parameters.

## Outputs and interpretation

**Rows versus supports**: The status tally counts every outside row, including undecided rows. The decided-support count deduplicates keys, retaining a set of SAT/UNSAT labels. Repeated rows are not independent supports.

**Agreement**: A shared key agrees when the local label is present in the outside label set. An outside set with both SAT and UNSAT agrees with either local label; no conflict count is reported.

**New and local-only supports**: New means absent from the local decided dictionary. The final local-only count is restricted to step 40. Neither result establishes a new mathematical discovery.

## Failure modes

- The join ignores weight cap, word width, initial-state law, encoder edition and other constraints. Support agreement is not evidence of equal models.
- Contradictory outside labels can be counted as agreement. Preserve conflicting rows before any independent-verification claim.
- The last local decided row wins. Across multiple files the unsorted glob does not supply a documented conflict-resolution order.
- No local census matches is accepted silently and makes outside supports appear new. A missing outside CSV does fail.
- Sorting retains duplicate indices. The tuple (1,1,3) is not the same key as (1,3).
- Missing CSV columns and malformed numeric word indices raise exceptions. A partial tally is not a successful comparison.
- The historical 3,063-support figure is not recomputed by these tests. No saved verdict, collision or success rate is independently certified here.
