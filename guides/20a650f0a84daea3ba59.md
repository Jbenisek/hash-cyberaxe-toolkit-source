# Poseidon walk measurements: fit first-repeat hazards

Source: `research/levers_1028/pos_r31_walk/measure.py`

Public SHA-256: `ea3720d4bd96a2a28c8c54cadcba9f4f5f42c1d7b3f4d3f5fb65d30ac03e3629`

## Reviewed usage contract

A historical reduced-width first-repeat study comparing a concrete Poseidon-derived walk with a keyed SHA-256 control. It fits a hazard multiplier and profile-likelihood interval. This guide documents the unchanged estimator and its limits; it does not certify the real map or a full-width attack probability.

## Source inspection and available execution evidence

static-source-review; extracted-estimator-and-synthetic-run-wiring-passed; no original rho import or research campaign.

The lesson enumerates 3,413 tiny synthetic maps and runs short deterministic fixtures. The original first-repeat routine stores all distinct visited values and has no timeout: at most N evaluations and O(N) stored states for a deterministic map closed on N states. Each original real step also pays the unknown F evaluation cost. No full-width operation price follows from this guide.

## Declared inputs

**Historical command**: python measure.py w trials seedbase, run only with the intended sibling rho.py and its dependencies. The header says r24 and 96 maps, but executed behavior comes from m.make_F, m.kappa_of and m.G_SET. Those dependency implementations are not audited by this lesson.

**Trial identity**: Trial k uses random.Random(seedbase*1000003+k), selects a map index in range(m.G_SET), then a start in range(2^w). Reusing the same arguments repeats the study, not an independent replication. Zero or negative trials are not rejected.

**Bit projection**: Real feedback is (F(v)>>SHIFT)&(2^w-1), with integer SHIFT default zero. The control always takes low bits of the first eight SHA-256 bytes, little-endian, and encodes its input into eight bytes. SHIFT is not applied to the control. Widths above 64 are not a matching control domain and may overflow that encoding.

**Fitting domain**: loglik uses hazards c*n/N without checking they are probabilities. mle searches [0.05,4], and interval searches [0.02,6] using the asymptotic 3.84 likelihood-ratio cutoff. Domain errors, boundary fits and empty samples need explicit handling before treating a result as evidence.

## Outputs and interpretation

**Original JSON summary**: w, K and seedbase, plus c, lo, hi rounded to four decimals and sum_t for real and ctrl. SHIFT, map indices, individual repeat lengths, source hashes, elapsed cost and fit diagnostics are absent. sum_t does not suffice to reconstruct the likelihood.

**What T counts**: first_repeat includes a return to the initial value. The permutation v -> (v+1) mod 4 repeats at four but has no distinct-input collision. Recovering two distinct predecessors is a separate obligation; a nonempty tail entering a cycle supplies them, a pure cycle does not.

**Bounded publication replay**: Sixteen cases extract five unchanged functions. They enumerate all 3,413 maps on one through five states and reproduce exact repeat-index counts, fit failures, seed identity and shift/control behavior. A synthetic map stand-in tests run wiring. No real Poseidon map is imported or executed.

## Failure modes

- A repeated state is not necessarily a collision between distinct inputs; verify the recovered predecessor pair.
- For c=1, the finite random-function law is normalized. For c<1, the first N fitted hazards leave positive survival mass; for c>1 they can exceed one. A global probability family needs an explicit valid endpoint or other model.
- loglik(4,[1],1) returns log(4) rather than rejecting a probability above one. Other invalid hazards raise ValueError during fitting or interval search.
- Empty samples receive a fitted value; short samples can hit the fixed upper fit bound. The interval's 3.84 cutoff does not make it an exact finite-sample guarantee.
- The output omits raw lengths and SHIFT. Retain them, chosen map indices, source identities and boundary/domain diagnostics separately for any new study.
- Truncation with feedback changes the dynamical system. Reduced-width deficits neither establish nor refute the full-field fixed-map success premise.
- No original rho dependency, historical measurement table, complete source family or attack price is validated by these fixtures.
