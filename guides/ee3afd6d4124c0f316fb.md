# Trail-family index: grouping semantics and representative selection

Source: `research/tools/profile/trail_families.py`

Public SHA-256: `db96c9a3d3d7670815487cdb43a923918911e6d372dbb131f1bb4f5efbfe7180`

## Reviewed usage contract

Group characteristic XML files by filename prefix and the ordered W rows containing lowercase u/n. Select a representative using saved SAT labels and parseable times, then write a family table. This is an organizational heuristic, not a solver or scientific equivalence test.

## Source inspection and available execution evidence

static-source-review; seven-disposable-writer-cases-passed; historical-library-not-regenerated.

One pass over the gate ledger and XML texts, then group sorting. No complete solve time, attack saving or expected representative quality follows from the grouping ratio.

## Declared inputs

**Workspace tree**: No CLI arguments. Resolves the research directory three parents above its own file and reads game/climber/guided/chars/library, including IV_GATE.tsv. Copy the script and selected inputs into an isolated matching tree before running it.

**XML-like rows**: Reads .xml files from unsorted os.listdir. Matches nonnegative numbered rows with 32 non-whitespace A, E and W symbols. The support signature retains row order and only rows containing lowercase u or n. x-only differences, state pins and sign orientation are ignored by the key.

**Nominal steps**: The step label is the filename substring before its first underscore, not the XML option n. Identical content under different prefixes can belong to different groups.

**Gate ledger**: Tab-separated member name, status and time text. Last duplicate names overwrite previous records. Only exact status SAT and a time whose period-stripped string contains digits only are counted. The first whitespace-delimited time token is used.

## Outputs and interpretation

**FAMILIES.tsv**: Replaces the library's family table with steps, members, sat_at_row12, W_diff_rows and representative. The row-12 label is fixed text: the tool does not validate which gate produced the ledger.

**Representative**: Among qualifying SAT entries, minimizes (float time, member name), so equal times use lexical order. Otherwise selects the first member seen by the unsorted filesystem scan. Sorts output groups by decreasing SAT count and member count; tied groups retain insertion order.


### Build a new index in an isolated copy

Working directory: A disposable tree containing research/tools/profile/trail_families.py and research/game/climber/guided/chars/library inputs

```text
python -I -B research/tools/profile/trail_families.py
```

Preserve input hashes, normalize member names and times before use, and inspect every representative against its actual XML. The script writes FAMILIES.tsv relative to its own location, not the shell directory.

Expected: One table row per filename-prefix/ordered-signed-support key. The number of groups and chosen representatives depends on the supplied files and gate ledger.

## Failure modes

- A representative's SAT or UNSAT status cannot be inherited by other members: signs, state pins, configured steps and other constraints may differ.
- Scientific notation such as 1e-3 is ignored as a candidate time, while malformed 1.2.3 passes the prefilter and raises ValueError in float conversion.
- An empty third gate field raises IndexError. On a failure before writing, an older FAMILIES.tsv remains and must not be mistaken for fresh output.
- Reordered or duplicate W rows are not canonicalized. An x-only trail can acquire an empty support key.
- Without a qualifying SAT entry, representative choice depends on filesystem enumeration order.
- Running the original script in place overwrites the live family table; the publication tests used only temporary synthetic copies.
