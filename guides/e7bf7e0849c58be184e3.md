# SHA-256 r38: the A0-variant plane-program interface

Source: `research/checks_1015/pa_src/R38V/experiments/a0lean38.py`

Public SHA-256: `4874d8816133bbf9e8c10be9053216a3361e71e64008a98a3d33ea8613699877`

## Reviewed usage contract

The pinned program combines an A0-variant construction, W7 class screening, a twelve-bit E16 prefilter and exact row/tail checks. It declares ninety classes of 3840 members and seven generated 256-bit plane programs. The source credits HASH$CyberAxe for the class schedule and earlier published characteristic work. This contract covers bounded arithmetic and interface checks, not exhaustive class sizes, sampling laws or a complete attack price.

## Source inspection and available execution evidence

static-source-review; Copied finite scalar/generated-filter fixtures and mocked Q3 dispatch; no class enumeration, online trial, SMC, full calibration, ledger or attack.

The bounded publication fixtures use seven small generated programs and no class lists. The two copied CLI controls have ten-second timeouts. No time estimate is promised for real selftest, calibration, SMC or full ledger modes.

## Declared inputs

**Source edition**: Use the exact R38V a0lean38.py download and its hash. Comments mentioning 64 classes and 245,760 selected variants remain in places, while this copy has ninety class descriptors. Treat the executable descriptors and each experiment law separately; do not silently substitute one historical edition for another.

**Command-line modes**: Positional ledger, calibrate and selftest run substantial research calculations. Every other argument falls through to JSON stdin; there is no dedicated --help mode. The examples below use an empty online request or a copied-module declaration read.

**JSON dispatch**: experiment_id containing the case-sensitive substring online selects online_experiment; every other string selects q3_experiment, including unknown names. Each trial needs trial and a string seed. Online rows run for trial<6; Q3 replicates run for trial<20. These checks do not reject every negative or duplicate trial index.

**Pooled Q3 row**: trial=20 produces a pooled row only after exactly twenty replicate rows have already been processed in that request. The function does not enforce unique trial IDs or seeds. Validate a distinct preregistered seed schedule before interpreting the pooled estimate; duplicated rows are not independent evidence.

**Plane-program contract**: The generated program has one output pass plane and a 64-register allocator with explicit loads, stores and spill reloads. Its twelve tested positions are a necessary prefilter for the listed row-16 words, not the complete tail condition. Synthetic mask-compatible lanes can test its arithmetic without enumerating research classes.

## Outputs and interpretation

**Finite scalar controls**: Sixteen fixed compression fixtures agree with an independent 38-step reference, sixteen E16 fixtures agree across three source formulations, and the archived common-chosen-CV pair independently replays. Three full-64-step hashlib fixtures gate the reference. No new witness was discovered.

**Generated programs**: Seven allocated single-output programs agree with scalar pre_ok on 3584 synthetic shape-compatible lanes. Their instruction counts, in group order, are 1410,1413,1421,1426,1425,1426,1425; allocated spill-slot counts are 14,14,15,15,15,15,15. These finite inputs are not asserted to be accepted class members.

**Finite filter controls**: All thirty-two listed row-16 values and their single-bit neighbours give 928 distinct controls agreeing with the full row-16 definition. Another 1024 fixed-seed W7 cases agree with inF7, and all 256 one-hot lane positions scan correctly. This is not exhaustive validation of all 32-bit words.

**Online-test format**: A non-null online row contains two 128-byte encodings, a common first block followed by the constructed second block. Its export condition is that filter, cell and lane mismatch counters vanish, not final digest equality. This is a local online consistency control, not automatically an ordinary-hash collision.

**Q3 format**: A Q3 pair is 96 bytes per side: eight common chosen-CV words followed by sixteen message words, all big-endian. The real sampler rebuilds candidate pairs, verifies compression equality and construction conditions, and checks step3b acceptance. The format is not an ordinary 96-byte message hashed from the standard IV.

**Zero and pooled estimates**: When a replicate has no success, log2_estimate is serialized as 0.0 with estimate_zero=1. Read that flag: it does not mean probability one. The pooled mean uses linear estimator values, not the mean of their logarithms. The trial-20 row is order-sensitive.

**Accounting output**: Mach separates target-compression units from modeled primitive operations. ledger retains q3_log2=-97.7838 and other tail/cap premises, and its integer certificate bounds a computed N/C. Such rounding does not prove those probability premises, full compiler correctness or the host Python process memory.

## Imports

- Python 3 standard library; descriptors and advice variants are compressed in the source. No network lookup is needed.
- Finite verification uses the separately pinned project SHA-256 reference and disposable copied source, without executing the reference random CLI.
- Full calibration enumerates the twenty relevant W7 bits (2^20 assignments) and materializes selected class data. Full selftest additionally runs an online trial and an SMC replicate; neither is a lightweight smoke test.

## Failure modes

- An unknown ID silently selects Q3 unless its name contains online. Validate the intended experiment identifier before invoking nonempty trials.
- Twenty duplicate trial IDs and seeds can satisfy the pooled-row count. The mocked control reproduces this interface behavior without running a sampler; it does not assert that any historical experiment actually reused seeds.
- first_lane requires a nonzero plane. Zero never reaches its break condition. The caller uses while x; do not call the helper with zero as a standalone smoke test.
- A non-null message pair has mode-specific semantics. Always distinguish chosen-CV compression pairs from ordinary-message pairs and from local consistency exports.
- The source uses modulo reduction in Shake.below. An exact uniform-choice proof cannot be inferred for arbitrary non-power-of-two bounds merely from a pseudorandom seed.
- Cached class members, batches, instructions, machine dictionaries and diagnostic objects are Python research representations. The modeled roughly-one-mebibyte layout is not a measured RSS bound for this interpreter.
- The 512 embedded variants are finite advice, not a proof of uniform sampling over every current class member or every changed class schedule.
- Do not relabel empirical Q3 inputs as exact because the final cost certificate uses large integer powers. Full price premises remain separate.
- Use Python without -O when replaying assertion-based evidence checks.
