# BLAKE3 early halfsearch (pkg5): 60/62-byte construction and diagnostic counts

Source: `research/pkg5/blake3-r2/experiments/halfsearch.py`

Public SHA-256: `8b1b4a16e203f6984d00f05a4ea83634b17282fa30504c18b797c9d014c35328`

## Reviewed usage contract

This early two-round BLAKE3 edition constructs pairs of 60/62-byte messages with equal digest words 0, 2, 5 and 7. Its small residual-search mode additionally targets the low byte of word 1, not all remaining digest bits. A separate seven-lane counting model diagnoses the two-stage procedure. These three roles must not be merged into a claim that the supplied Python program executes a complete priced collision attack.

## Source inspection and available execution evidence

static-source-review; three fixed constructions with independent digest comparison; four finite batch fixtures, finite flags/rule patterns and empty/invalid CLI; no residual search or full selftest.

The scalar-only example constructs one pair and recompresses its two messages. The diagnostic batch reports 100 stage-A operations/loads and 138 stage-2 operations/loads under its declared model, always executing both for inspection. Actual conditional execution, context setup, member-list creation, run control, final verification, complete memory and success probability need separate accounting. No elapsed-time benchmark or complete attack price is certified.

## Declared inputs

**JSON interface**: With no command-line arguments, read one request from stdin: schema_version=1, target_profile=blake3-r2-prefix-v1, event.kind=digest-xor-mask, experiment_id=half-collision or residual-search, and trials containing trial IDs and hexadecimal seeds. Only the event kind is validated; mask/value content is not checked. Empty requests return an empty trial list without entering either experiment.

**Context and class**: This edition uses 9 context words plus a separate 32-bit alpha. Class mask 015fe7c1, value 00036181; 65,536 members in 9,363 seven-lane batches. Use 0 <= k < CLASS_SIZE and 0 <= j < BATCHES. class_member does not reject out-of-range indices: CLASS_SIZE aliases zero and -1 aliases the last member.

**Exact rule and machine model**: The active rule has 6 parity conditions. Seven 36-bit lanes fit in a 256-bit word; the declared register limit is 16. Local additions/XORs/ANDs/ORs/shifts, comparisons and branches are charged as model operations, while constant and list fetches are loads. These are not Python host instruction counts.

**Message boundary**: The 60-byte A and 62-byte B share a zero final word in their zero-padded 64-byte representations. Do not substitute the later 55/63-byte construction or its constants.

## Outputs and interpretation

**half-collision**: One deterministic 60/62-byte pair per seed. Output preserves the caller trial ID, message_a_hex and message_b_hex, with no observations for this mode. Equal words 0,2,5,7 mean 128 equal digest bits, not a full collision. The three fixed publication fixtures were independently recompressed, not used to estimate a success probability.

**residual-search, not executed in this audit**: Visits up to 65,536 class members cyclically from a seeded start, stopping at the first pair whose word-1 residual has a zero low byte. That adds eight bits to the half-digest event, giving 136 equal bits. Failure returns null messages and tries=CLASS_SIZE. The initial diagnostic batch contributes observations but does not determine the returned pair. This publication audit ran no such search.

**Counted batch components**: The four tested batches each report stage A: 64 operations + 36 loads; stage 2: 96 operations + 42 loads. Their model peak is 11 registers. Constant groups have 14 per-context entries and 7 per-alpha entries. Setup of those constants is outside the counted batch.

**Diagnostic versus actual run control**: packed_batch always evaluates both stages so their words and charges can be checked. Its budget comparison is counted, but its returned Boolean is not used to stop execution. Three controls at one below, at and one above the declared stage-2 budget still execute every part and yield the same test output. This is not an implementation of a budget-enforcing full run.

**Tail padding and class enumeration**: The last packed word contains only two distinct remaining members; its five spare lanes repeat the final member. Physical lanes are therefore not seven new trials in the final batch. Finite endpoint/index checks do not constitute exhaustive enumeration of the entire class.

**Finite evidence**: Three fixed seed pairs agree with an independent two-round implementation on all six computed digests. Four boundary/interior batches check 28 lanes against complete scalar compression, exact per-part table counts, register peaks and lane-sum bounds. All 128 zero/nonzero flag patterns and all 256 relevant rule-input patterns pass. Five rejected requests and two empty modes check the CLI. These tests are not universal construction proofs, mass retention or measured opening rates.

## Imports

- Python 3 standard library: hashlib, json, struct and sys. SHAKE expands the supplied seed; no external BLAKE3 package is required by the archived script.
- The publication audit additionally uses Node.js and the library’s separately checked BLAKE3 reference for independent recompression. That reference is not needed for the scalar-only example.

Working directory: A disposable directory containing the downloaded and hash-checked halfsearch.py

```text
python -I -B -c "import runpy; m=runpy.run_path('halfsearch.py',run_name='bounded_copy'); a,b,_=m['half_collision'](b''); da,db=m['compress2'](a)[1],m['compress2'](b)[1]; assert all(da[i]==db[i] for i in (0,2,5,7)); print(len(a),len(b),'128-bit agreement')"
```

## Failure modes

- Do not call --selftest for a cheap smoke test: it also enumerates the complete class list. Use the documented fixed example.
- Do not treat a requested mask as validated merely because main accepts it; the interface checks only event.kind.
- The output half pair and the toy 136-bit event are not full 256-bit collisions. Independently check the target predicate on the actual length-delimited messages.
- Both stages are deliberately evaluated in the diagnostic. Do not infer a measured gate-opening rate from its operation totals or regard its budget comparison as enforced stopping.
- Require unsigned 32-bit context values and valid class/batch indices; helper routines do not form a validated public API.
- The example and checker use assertions; do not run them with Python -O. A small set of fixture passes is not an all-input proof.
- Keep the source hash, message lengths, class mask, active rule and cost table together. Later files with the same name have different constructions and accounting.
