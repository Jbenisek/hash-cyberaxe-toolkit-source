## Reviewed usage contract

This five-round binary program has 31,606 operations. Unlike the original compact edition with 64/16 fields, its 63/17 layout fits the declared trail-start envelope. It still omits at least 248 bytes for large recovery immediates. Both use a zero-prefix message family and a fixed output mask. Local adder truth tables and finite complete-hash fixtures do not establish an exact full-width success law. The source credits jungjipdo’s 6ae36351 proofs 3.3 and 3.4 for the pivot adder and masked walk, and identifies its surrounding implementation with 0a9640ed / 3356413f.

## Declared inputs

**Actual target and complete message**: ROUNDS=5, UNIT=1054, standard IV, counter 0, length 64 and flags 11. The message is 32 zero bytes followed by little-endian 256-bit x. Some prose still says seven rounds or describes an eight-byte/two-byte entry. Executed constants and fresh fixtures determine the five-round target and 63/17 fields.

**Full-adder primitive and attribution**: Choose a pivot p so x and y have equal polarity. With u=x XOR p and v=y XOR p, sum=u XOR y and carry=(u AND v) XOR p. Polarity-aware AND/OR emission yields five binary operations for three variable inputs.

**Masked-walk interpretation**: The circuit stores g(x)=f(x) XOR q, with q derived from output polarities. Fixed q preserves equality of outputs exactly but changes trajectories. f_scalar returns the unmasked digest. A matching mask does not transfer a random-mapping or probability premise.

**Supplied budget, not numerical plan selection**: The bounded ledger supplies Tp=22 and B=10^35, 79,940 endpoint records, kappa=14, 800 declared registers, slice size 2^48 and one allowed cut. The numerical budget helper is replaced by that supplied constant. No claim is made that these parameters reach a particular success probability; the default optimizer was not run.

**Organizer experiment meanings**: bsrho-n18 combines one reduced masked target attempt with a keyed BLAKE2b ideal-control attempt. T1 instead iterates unmasked f with a fresh first message half. proj-k0-w256 unmasks stored values before seven 21-bit projections; a w0 repeat is not a full-digest collision. Trial modulo 3 selects one of three input families.

**Safe example boundary**: Use the compiler-only command below in a disposable directory with the pinned download. It performs no walk or probability optimization. --selftest includes actual collision attempts; --stats runs campaigns; --ledger and --loss select/evaluate numerical plans. --gen-c emits source but does not compile it. Original search routes and launch scripts were not run.

## Outputs and interpretation

**Local full-adder identity**: All 512 bit/polarity/constant-substitution cases pass under this source pin, including 64 distinct-variable cases. The latter emit 5 abstract gates. Wrong-sum and wrong-carry controls are rejected in all cases. Bitwise lifting proves the local identity, not a primitive’s hardware price or the complete generator.

**Five-round arithmetic and allocated program**: 256 complete-message fixtures match the separately pinned reference, whose two known answers are checked. Two masked steps, 18/20-bit fixtures and seven packed values pass. All 31,606 allocated instructions are structurally checked across 16 compiler chunks, including operands and final outputs. Register extent is 771; packed recovery uses 1,072 operations. Changed-operator and changed-register controls are rejected.

**Exact supplied-budget numerator**: N=10851588049728893187949312295849388150048 word operations for the artificial supplied budget, reference unit 1054. Body=31,643 = 31,606 kernel + 34 filter + 3 loop operations. The integer sum is exact for the declared formulas; it is not a default price, a complete handler audit, a success guarantee or an accepted score.

**Representation boundary**: The main circuit already uses the binary basis, with no select-primitive discount to remove. Both source layouts price eight large packed recovery mask immediates too cheaply under their five/36-byte convention. Their minimum missing charge is 248 bytes: the declared 1,048,504-byte search phase becomes at least 1,048,752, or 176 over one MiB. This is a lower bound, not a repaired layout or replacement score.

**Memory and preprocessing formulas**: Declared code: 207,120 bytes; table: 79,940 ten-byte records; counters/copy: 16,384 bytes; register file: 25,600. Phase totals are 311,904 setup and 1,048,504 search bytes before the omitted-code correction. Setup charges factor 200 times (2 times 64,108 generator calls + 31,606 instructions), plus a fixed allowance. These abstract quantities are not Python RSS or native instructions.

**Fields and two-pass recovery**: The endpoint packs a 63-bit key and 17-bit trail ID into ten bytes; the 80,198-start envelope fits 131,072 field values. It stores no length. Recovery recomputes both lengths, aligns and advances; the ledger charges two passes at 1,072+64 operations per batch plus 600. Six one-batch constant-map fixtures test an artificial pair and budget/no-hit exits, not a BLAKE3 collision.

**Domain and cache boundaries**: Four nonnegative record roundtrips and two upper-overflow controls pass. Negative packed fields are accepted and can alias maximal unsigned fields; internal IDs are nonnegative. The B cache omits Sb. A synthetic oracle demonstrates stale reuse when Sb changes, not a failure of the one fixed archived default. Validate inputs and isolate the cache for parameter sweeps.

**Statistics and dispatch**: [5,5,5,7] gives two duplicate entries but three equal pairs. Projection expressions keep 21 bits where comments say 22. Mocked dispatch ignores target metadata, retains repeated/negative trial IDs and rejects unknown experiment names. A synthetic Halt preserves prior counters. These interface observations are not a schema guarantee or complete work count.

**What has not been replayed**: No retained five-round WebAssembly artifact, fresh C build, default numerical optimization, exact probability theorem or original search was run. The three-round generator ZIP covers another identity. Four-round verdict 2cf0d4a5 is not presented as a five-round adjudication.

## Failure modes

- Neither declared memory layout includes the demonstrated minimum 248-byte correction.
- The supplied-budget numerator is not the default, optimized, accepted or success-certified price.
- Do not transfer a four-round adjudication or a three-round replay kit to this five-round source.
- Read executed constants rather than stale round or endpoint-field comments.
- Compare primitive bases before comparing operation counts.
- Validate negative fields; reset the budget cache when varying omitted parameters such as Sb.
- Unmask outputs before digest comparison and distinguish partial-output repeats from full collisions.
- Preserved output equality under a fixed mask does not prove a random-walk success law.
