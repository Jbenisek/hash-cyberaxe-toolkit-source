## Reviewed usage contract

This six-round select circuit has 26,070 abstract gates, including 6,360 selects. Binary expansion adds 12,720 operations, reaching 38,790. This normalizes arithmetic expressions; it is not a new allocated program or adjudicated score. The source credits jungjipdo’s 6ae36351 proof 3.4 for the masked walk, with surrounding implementation f07a5442 / 0a9640ed / 3356413f. Fixed examples and local truth tables do not establish the full-width success law.

## Declared inputs

**Actual target and complete message**: ROUNDS=6, UNIT=1262, standard IV, counter 0, length 64 and flags 11. The message is 32 zero bytes followed by little-endian 256-bit x. The executable target and six-round source identity are checked.

**Full-adder primitive and attribution**: The variable full adder uses two XOR gates and one select: choose equal-polarity x,z, set t=x XOR y, sum=t XOR z and carry=select(t,z,x). The machine model charges select as one three-input operation; the Python expression expands it into Boolean operations.

**Masked-walk interpretation**: The circuit stores g(x)=f(x) XOR q, with q derived from output polarities. Fixed q preserves equality of outputs exactly but changes trajectories. f_scalar returns the unmasked digest. A matching mask does not transfer a random-mapping or probability premise.

**Supplied budget, not numerical optimization**: The fixture supplies Tp=22 and B=10^35, kappa=14, 81,955 endpoint records, 800 declared registers, slice size 2^48 and one allowed cut. The numerical budget helper is replaced by this constant. No success probability or optimized price is inferred.

**Organizer experiment meanings**: bsrho-n18 combines one reduced masked target attempt with a keyed BLAKE2b ideal-control attempt. T1 instead iterates unmasked f with a fresh first message half. proj-k0-w256 unmasks stored values before seven 21-bit projections; a w0 repeat is not a full-digest collision. Trial modulo 3 selects one of three input families.

**Safe example boundary**: Use the compiler-only command below in a disposable directory with the pinned download. It performs no walk or probability optimization. --selftest includes actual collision attempts; --stats runs campaigns; --ledger and --loss select/evaluate numerical plans. --gen-c emits source but does not compile it. Original search routes and launch scripts were not run.

## Outputs and interpretation

Wrong-sum and wrong-carry controls are rejected in every case. This proves the local Boolean identity, not primitive pricing or complete-generator correctness.

**Six-round arithmetic and allocated program**: 256 complete-message fixtures match a separately pinned reference with two known-answer checks. Two masked steps, 18/20-bit fixtures and seven packed values pass. All 26,070 allocated instructions are structurally checked across 14 chunks; register extent is 771. Packed recovery uses 1,307 operations. Changed-operator and changed-register controls are rejected.

**Exact supplied-budget numerator**: N=11888228088322483450441635581206641788153 word operations in the declared formulas, reference unit 1262. Body=26,107: 26,070 main operations + 34 filter + 3 loop operations. This supplied-budget sum is not the default, optimized, accepted or success-certified attack price.

**Representation boundary**: The 6,360 select primitives expand from one to three binary operations each: 26,070 + 12,720 = 38,790. No lowered/reallocated complete program was generated. Eight large packed-recovery immediates are priced as short instructions. Under the source five/36-byte format, at least 248 bytes are missing: the 1,048,509-byte search phase becomes at least 1,048,757, or 181 over one MiB. This is a lower bound, not a repaired layout or new adjudication.

**Memory and preprocessing formulas**: Declared code 186,975 bytes; table 81,955 ten-byte records; counters/copy 16,384 bytes; register file 25,600. Declared phases: 295,799 setup / 1,048,509 search bytes, before the correction. Setup uses factor 250 times (2 × 53,052 generator calls + 26,070 instructions), plus a fixed allowance. These are abstract charges, not native RSS or host instructions.

**Fields and artificial recovery controls**: The endpoint packs a 63-bit key and 17-bit trail ID into ten bytes. The conservative 82,213-start envelope fits 131,072 values. No length is stored; recovery recomputes lengths, aligns and advances. The ledger charges two passes at 1,307+64 operations per batch plus 600. Six one-batch constant-map fixtures exercise artificial recovery and budget/no-hit exits; they are not BLAKE3 collisions.

**Domain and cache boundaries**: Four nonnegative record roundtrips and two upper-overflow controls pass. Negative packed fields are accepted and can alias maximal unsigned fields; internal IDs are nonnegative. The B cache omits Sb. A synthetic oracle demonstrates stale reuse when Sb changes, not a failure of the one fixed archived default. Validate inputs and isolate the cache for parameter sweeps.

**Statistics and dispatch**: [5,5,5,7] gives two duplicate entries but three equal pairs. Projection expressions keep 21 bits where comments say 22. Mocked dispatch ignores target metadata, retains repeated/negative trial IDs and rejects unknown experiment names. A synthetic Halt preserves prior counters. These interface observations are not a schema guarantee or complete work count.

**Not replayed or inferred**: No retained six-round WebAssembly artifact, fresh C build, default optimizer, exact probability theorem or original search was run. Earlier replay kits and saved verdicts belong to other source identities; no earlier adjudication is transferred here.

## Failure modes

- Neither declared memory layout includes the demonstrated minimum 248-byte correction.
- The supplied-budget numerator is not the default, optimized, accepted or success-certified price.
- Do not transfer earlier-round adjudications, probability claims or replay kits to this six-round source.
- Read executed constants rather than stale round or endpoint-field comments.
- Compare primitive bases before comparing operation counts.
- Validate negative fields; reset the budget cache when varying omitted parameters such as Sb.
- Unmask outputs before digest comparison and distinguish partial-output repeats from full collisions.
- Preserved output equality under a fixed mask does not prove a random-walk success law.
