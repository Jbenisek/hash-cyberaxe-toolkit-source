# BLAKE3 three-round rho: inspect prefix walks and packed recovery

Source: `research/blake3_r3/candidate_blake3/experiments/rho.py`

Public SHA-256: `4a5bc2ef7643dc0c1908ad6a7c248e72154302c91c0daffe340f1f4b8db6680f`

## Reviewed usage contract

This historical candidate searches for equal low digest bits using distinguished-point walks on three-round BLAKE3. Messages are exactly 64 bytes: 32 zero bytes followed by a 256-bit little-endian chain value. Seven lanes share a 256-bit packed arithmetic circuit. Its organizer entry point uses a 22-bit event; a separate attack() function declares a full 256-bit target. Neither the source filename nor a passing prefix experiment establishes a full collision or its success probability.

## Source inspection and available execution evidence

static-source-review; copied finite self-test, seven independent digest checks, declared-budget arithmetic and mocked interface controls; no search.

The documented self-test uses 10 seven-lane packed batches and 70 scalar digest evaluations, plus circuit generation and fixed SHAKE input preparation. The emitted batch has 595 modeled arithmetic operations. Real searches are much larger: the default allows 60 attempts per trial at n=22; attack() separately calls one n=256 attempt. Exact declared budgets for n=22,32,40,256 are in the bounded report, not certified attack costs.

## Declared inputs

**JSON request**: Default execution reads trials. Each row needs seed and trial keys. The caller trial identifier is preserved, and seed is incorporated through string formatting into SHAKE-256 inputs seed/attempt-index. There is no hexadecimal-seed validation. schema_version, target_profile and event are not checked, so accepted JSON is not evidence that the requested target was tested.

**Compression and message profile**: Three rounds, standard IV, one 64-byte block, counter zero and flags 11. State output is v[i] XOR v[i+8], serialized as eight little-endian words. The iteration keeps the low n bits of that little-endian digest integer. n=22 in run_trial defaults, not an arbitrary event mask supplied by the request.

**Guarded import and finite setup**: The module builds and compiles its packed circuit during import. main is protected by a name guard; an imported module does not launch a search. --selftest runs 70 deterministic packed-versus-scalar comparisons. --ledger recomputes the n=256 formula and prints approximate logarithms. Any other command-line spelling falls through to the JSON experiment; use the exact documented option.

## Outputs and interpretation

**Trial rows**: Each response row retains its caller ID and has message_a_hex and message_b_hex, either two 64-byte message encodings or null values. The default search tests equality of only 22 digest bits. A non-null default result is not a 256-bit collision certificate; independently verify the intended full profile.

**Observations undercount halted work**: attempts counts each started attempt, up to 60 by default. batches accumulates counts only when search returns normally. When search raises Halt, that attempt is skipped and none of its executed batches is included. Even on normal returns, recovery evaluations are not added to this main-loop counter. Thus observations.batches is not total executed work and cannot price a run. Synthetic controls exercised one halt and two normal returns: three attempts, only 11 reported batches.

**Circuit and ledger**: The traced batch has 595 emitted arithmetic instructions: 100 add, 88 xor, 80 shr, 167 and, 80 shl and 80 or. These are trace-model counts, not Python instructions or a complete machine implementation. ledger(n) combines main, slices, stage2, events, recovery and init as exact fractions; the printed compression-unit conversion divides by 638. This audit recomputes that formula but does not certify its probability or all cost bounds.

**Distinguished-point recovery limits**: The table indexes only 64 bits above the distinguished-point mask. At n=256 this is a fingerprint, not the complete endpoint. A matching key triggers recovery; failed recovery raises Halt rather than exporting an unchecked pair. Stage-2, table, batch and trail-age limits can also terminate work. Accounting for these losses is separate from checking the packed digest arithmetic.

## Failure modes

- Do not run the default CLI expecting a quick syntax or replay check: it starts reduced-prefix searches for supplied trials. Use --selftest for the bounded example.
- Changing target_profile or event in JSON does not change the fixed default 22-bit target. The parser ignores these fields.
- Do not infer total work or success rate from observations.batches: budget-halted attempts lose their batch counts.
- The attack() helper is not invoked by main or --ledger. It runs one full-width attempt and can propagate Halt; it is not a guaranteed-return wrapper.
- A 64-bit table-key match is only a recovery trigger at full width, not a collision certificate. Recovery and resource-limit losses must enter any success proof.
- Packed/scalar agreement and seven independent fixed digests establish finite arithmetic controls, not random-map behavior, cutoff-loss bounds, register allocation or a 256-bit attack success law.
- This guide covers the pinned early candidate only. Other rho.py editions have different schedules and budgets; equal filenames do not establish equivalence.
