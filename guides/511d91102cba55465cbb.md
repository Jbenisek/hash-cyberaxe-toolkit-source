# Pin screen: detect one contradictory SHA-256 state window

Source: `research/tools/screen/pin_screen.py`

Public SHA-256: `b55bacce79b858cb762121f5e2c6266ec8f35b31d91a11a1ac338c66475da1ff`

## Reviewed usage contract

Detect a nonzero W difference inside a complete five-row equal-state window. This is a narrow necessary-condition screen for parsed characteristic rows, not a general satisfiability checker.

## Source inspection and available execution evidence

static-source-review; seven-synthetic-pin-tool-cases-passed; no solver or research campaign.

Linear text parsing and five-row lookups. No solver or attack price is established.

## Declared inputs

**CLI**: python pin_screen.py XML... . Explicit input paths; --help is treated as a filename, not an option.

**Rows**: Lines matching integer A: symbols E: symbols W: symbols. All fields must appear. Duplicate indices keep the last row. Word width and complete XML validity are not checked.

**Symbols**: A/E strings containing only -, 0 and 1 count as equal. Any x/u/n symbol (including uppercase) makes W definitely different. Unknown ? does not. Detection requires r>=4 and every row r-4..r.

## Outputs and interpretation

**IMPOSSIBLE rows**: Detected contradictory pin windows in this file, not a proof that the entire message-difference cell has no other trail.

**ok**: No implemented obstruction found. Missing rows, other contradictions, schedule consistency and initial-state constraints are unresolved.

## Imports

- Python standard library only. Reads the named inputs, prints stdout and does not write them.

## Worked examples

### Create and screen a disposable fixture

Working directory: An empty scratch directory containing the downloaded pin_screen.py

```text
python -c "from pathlib import Path; z='-'*32; Path('fixture.xml').write_text('\n'.join(f'{r} A: {z} E: {z} W: '+('x'+z[1:] if r==4 else z) for r in range(5)))"
python pin_screen.py fixture.xml
```

Expected: IMPOSSIBLE rows [4], a tab and fixture.xml. This artificial constraint contradiction is not a collision.

## Failure modes

- ok is not SAT.
- A rejected pinned trail is not a rejected cell.
