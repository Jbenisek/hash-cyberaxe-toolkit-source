# SHA-2 XML templates: reproduce the corrected input masks

Source: `research/levers_1021/s256_r40_search/nldtool/mkxml.py`

Public SHA-256: `5bb0481f32e86ddc83e7b02624c0ff437e31dd4785d3233510b28cf931528b4b`

## Reviewed usage contract

Generate historical nldtool sha2, word-size-32 input templates. The retained exact source contains both superseded overconstrained masks and corrected versions so the research correction remains reproducible.

## Source inspection and available execution evidence

static-source-review; ten-generator-and-characteristic-controls-passed; no-solver-executed.

Small deterministic file generation, not a search-time or attack-price estimate. Each publication control has a ten-second subprocess timeout.

## Declared inputs

**Existing output directory**: python -I -B mkxml.py OUTDIR. The directory must already exist. The script executes at top level, writes every ordinary template and overwrites matching filenames. Use a new disposable directory, not a research result directory.

**Optional mode**: twoblock adds two h-bit-28 files. twoblock_reg accepts e/f/g/h followed by a decimal bit index, such as e0 f31 g15 h28. Validate bit indices 0 through 31 before calling; the script does not enforce this range. Unknown modes are silently ignored.

## Outputs and interpretation

**Ordinary templates**: 31 XML files with n=39, 40, 41, 42 or 43 and 32-character A/E/W masks. Negative state rows -4 through -1 precede round rows 0 through n-1. Whole-word '-' means an equal-pair difference mask, not an absolute zero word.

**Optional two-block masks**: twoblock produces 33 total files; four distinct twoblock_reg requests produce 39. Register e/f/g/h maps to input E-1/E-2/E-3/E-4 and output E39/E38/E37/E36 for n=40. A u input and n output are the intended opposite signed differences; no actual chaining pair or block is generated.

**Saved characteristic recount**: The portable replay checks 44 rows and 128 word masks against the pinned input: 380 single-bit conditions (A=60, E=283, W=37), including 167 signed differences (A=59, E=82, W=26). Symbol-set inclusion and mask widths are checked; modular feasibility and success probability are not.

## Imports

- Python standard library for generation. A separately reviewed nldtool setup would be required to interpret and solve the masks; this bounded audit neither bundles nor runs a solver.

## Worked examples

### Replay the portable generator and characteristic checks

Working directory: Extract mkxml-contracts.zip and open its mkxml-kit folder

```text
python -I -B replay.py
```

Uses only Python's standard library and temporary output directories. No solver is launched. The source and saved control are hash-pinned; changed files and optimized mode are rejected.

Expected: Ten controls pass, including a recount of 380 single-bit conditions and 167 signed differences. This is not a concrete collision or an attack-probability certificate.

### Generate into an empty scratch directory

Working directory: Folder containing the exact archived mkxml.py; create a new empty xml-out directory first

```text
python -I -B mkxml.py xml-out
```

Do not use an existing results directory. Inspect filenames and choose corrected variants deliberately.

Expected: 31 parseable XML files. No solver result or collision is reported.

### Generate four register placements

Working directory: Same source folder with a different new empty reg-out directory

```text
python -I -B mkxml.py reg-out twoblock_reg e0 f31 g15 h28
```

All four bit indices are in range. Equal input masks are not a standard-IV certificate.

Expected: 39 files: 31 ordinary templates and 8 register-specific files. Check 32-character mask widths before solving.

## Failure modes

- The original pinned T1314 file forces every expanded word 16 through 42 equal. FIX releases 21 expanded words while retaining zero-difference rows 24, 26, 39, 40, 41, 42. FIX2 additionally frees A and E rows 8 through 42. The older files remain present: select the intended correction explicitly.
- The B1 comment says standard IV, but this generator writes equal-input difference masks and no eight-word absolute standard-IV pins. Confirm the consuming model's initial values separately; equal chaining values alone do not imply the standard IV.
- A nonexistent output directory fails. An invalid register fails only after 31 ordinary files have already been written. Output existence is not proof of successful completion.
- An out-of-range e32 request exits zero and emits a 33-character mask. Validate input and every emitted width.
- Importing this source is not a safe way to access helpers: the file writes outputs at module top level. Repeated execution overwrites named outputs.
- Generated XML and commentary about historical initial-check failures are not SAT/UNSAT proofs, native collision witnesses or success probabilities.
- Live historical snapshot path is missing. Exact original bytes are retained under an explicit source hash.
