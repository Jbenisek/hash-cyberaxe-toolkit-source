# Door-price calculator: replay the historical window costs

Source: `research/game/climber/guided/sparsedoor/price.py`

Public SHA-256: `b386ed58a46e0805f5a4f8f517590ee58673b4dfad4bae9d333198369eb0c27f`

## Reviewed usage contract

Recompute historical window costs from fixed ledgers, estimated per-window upper/lower quantities and two declared tail-rate scenarios using the dated r39-style charge formula. Synthetic-ledger examples check the interface. The historical attack law and sampled inputs retain their conditional status.

## Source inspection and available execution evidence

static-source-review; eight-synthetic-window-controls-passed; historical-ledgers-not-recounted.

Linear reads and elementary statistics in the selected windows, followed by two scalar price evaluations. This is a calculator cost, not the proposed cryptanalytic attack cost.

## Declared inputs

**Hardcoded ledger path**: No CLI options. Reads sorted WORK/led/win_*.json from a hardcoded local directory. Each JSON must be a nonempty array whose first object has numeric ops, distinct_claws and distinct_groups. Extra array entries are ignored.

**Sample count**: The Student-factor lookup has entries only for n=24 and n=73. Other counts fail. All claw denominators must be nonzero; the estimated claw and group/claw lower bounds also need positive usable values.

**Tail and benchmark assumptions**: The script fixes q=-74.4242 and q=-75.49, the 585/524288 factor, a -32 term and historical leader numbers. None is independently established from sparse-member inputs by this program.

## Outputs and interpretation

**Console**: Prints n, estimated mu+, c- and r-, then two five-decimal board prices and differences from dated leader constants. It writes no result file. Displayed historical leaders are not current leaderboard data.

**Arithmetic**: Means, sample deviations, t-factor estimates, logarithms and powers are floating point. Integer floor/ceiling operations occur before Fraction wraps the final work. An exact rational representation of that rounded work does not prove an exact success law or a rigorous upper bound.

## Imports

- The portable replay needs only Python 3.10+ and its standard library; its synthetic windows are created in temporary directories. Direct historical use additionally requires the exact external window ledgers and a separate audit of their statistical assumptions.

## Worked examples

### Reproduce the bounded synthetic fixture

Working directory: Extract sparsedoor-price-contracts.zip and enter sparsedoor-price-kit

```text
python -I -B replay.py
```

The wrapper validates its manifest and creates disposable 24- and 73-window sets; each window has ops=100, claws=10 and groups=5. These are deliberately artificial, not research measurements. No live ledger is read.

Expected: Eight controls pass. Both synthetic sets print mu+=100, c-=10 and r-=0.5; their two synthetic board values are 108.16402 and 109.22982. These numbers must not be filed as attack scores.

### Inspect a real ledger before direct use

Working directory: An isolated source copy with a separately reviewed ledger directory

```text
python -I -B price.py
```

First replace only WORK in the copied script, verify exactly 24 or 73 independent intended files and positive lower estimates, and audit all inherited assumptions. The publication audit did not execute this command on real ledgers.

Expected: Four summary lines only if all scalar operations succeed; exit zero does not prove the sparse head, transferred tail probability or complete price.

## Failure modes

- Unsupported or empty window sets fail the hardcoded factor lookup.
- Zero claws cause division by zero; empty arrays cause IndexError.
- Highly variable samples can make c- negative: the script prints the invalid statistics then fails in a logarithm, rather than returning a useful bound.
- Only the first array entry is used; additional window records in the same file are silently ignored.
- No sparse-head construction cost, transferred tail law, independence proof or present-day leaderboard verification is included.
