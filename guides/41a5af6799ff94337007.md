# SHA-256 tail sampler: observation batches, chosen IVs and saved calibration (best/dkbase)

Source: `research/pkg_r39_best_work/dkbase/sha256/experiments/r39tail.py`

Public SHA-256: `5bbd6117e33476bc77a0933808e95cfce526f00495c0be0dd0434cdb5930a3c0`

## Reviewed usage contract

Historical 39-step SHA-256 tail experiment using sequential Monte Carlo (SMC): it keeps and resamples candidate states across rows 18 through 23, then tests packed suffix candidates and checks survivors under a reconstructed common chaining value. The output is an observation batch, not a collection of message witnesses. A chosen common IV is not the standardized SHA-256 IV.

## Source inspection and available execution evidence

static-source-review; copied bounded arithmetic, embedded self-consistency and fully mocked main controls; historical sampler not run.

Do not use an empty main request as a cheap smoke test: main enumerates membership sets and calibrates before reading trials[0]. The two mask enumerations visit 2^14 and 2^17 submasks. Calibration requests 65,536 candidate lanes. If all six particle levels are reached, their configured proposal ceiling is 31,132,800 lanes, plus filtering, copying and resampling. The suffix stage considers 20*80*2048=3,276,800 lanes over 15 remaining steps, plus verification of survivors. Packed lanes are not individually priced word operations. These structural counts are not wall-clock measurements or a complete contest charge.

## Declared inputs

**One JSON request on stdin**: trials must contain at least 21 objects with string seeds: index 0 drives particle construction and indices 1 through 20 drive child batches. The strings are passed to random.Random, not decoded as hexadecimal. trial identifiers are not read. target_profile is not read or validated.

**Optional experiment_id**: If it equals one of the 14 stored r39-tail-01 through r39-tail-14 labels, an assertion compares selected aggregate outputs with that saved row. An absent or different identifier skips this final saved-row comparison, not the expensive experiment.

**Pinned parameters**: The source embeds NR=39, NP=800, NCH=20, NB=80, LF=2048, six row configurations, a baseline common CV, fixed message differences, masks and fourteen historical aggregate rows. Changing these creates a different experiment and can invalidate calibration assertions.

## Outputs and interpretation

**Observations rather than exported witnesses**: Every response row has message_a_hex=null and message_b_hex=null. Row 0 reports carrier/calibration observations. Rows 1 through 20 report attempted suffix candidates, hits, verified counts and four class counts. No successful messages or reconstructed CVs are emitted.

**Row identifiers and extra inputs**: Response trial values are integer positions 0 through len(trials)-1, not the caller identifiers. Extra inputs after index 20 add null-message rows without observations and do not trigger extra child searches.

**Interpretation of recorded counts**: The embedded table has 14 rows and 3,365 literal hits; the four saved class totals reconcile with each hit count. This recount does not certify those historical runs, independence, or a lower success bound. log2_carrier is an SMC-derived estimate, not an exact probability.

**Already catalogued known-answer specimen**: The full common CV and both messages match p_li39tab23s1_luna in the existing data/pairs39.json collection, whose separate replay includes feedforward. This is one existing specimen reused as a self-check, not a newly discovered collision or a second independent experiment.

**Bounded publication checks**: Two source copies were hash-pinned. Thirty-two scalar-versus-packed sigma comparisons, two zero/negation fixtures and the documented embedded self-check command passed. Fully mocked main controls reproduce renamed trial IDs, null outputs even with synthetic positive hits, extra rows and errors for empty/short batches and integer seeds. No original SMC or membership enumeration ran; no independent hash reference was used in these checks.

## Imports

- Python 3 standard library: sys, json, random, math and struct. The source embeds its data and arithmetic; no local module is imported.
- Replay depends on the exact source, parameters and pseudorandom implementation. Do not treat a seed alone as a complete historical execution record.

## Failure modes

- Empty or short trial lists fail by indexing rather than returning an empty successful batch; integer seeds fail when the code appends the string m.
- An empty particle pool returns no population; main does not recover before using the missing carrier value.
- Many consistency, saved-row and calibration checks are Python assertions and disappear under -O; do not run the experiment with assertions disabled.
- The saved table and Student-style lower-bound calculations do not establish independence or an exact success theorem. This guide has not validated their statistical assumptions.
- A nonzero hit count is not a portable certificate because the response omits messages and reconstructed IVs. Instrument and independently verify a dedicated witness export before making such a claim.
- The reference self-check is internal to the same source and uses a chosen common IV. It is not a standard-IV, full-round or independently certified result.
- The two source paths are byte-identical copies, not two independent experiments.
