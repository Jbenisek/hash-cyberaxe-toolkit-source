# SHA-256 pair encoder: set initial states and decode candidate words

Source: `research/game/climber/guided/minsup/sha_cnf.py`

Public SHA-256: `5a6b7373b8aac2312a9c017436c17ed4d29caed27343d959af76de687e33f1aa`

## Reviewed usage contract

Encode two n-step SHA-256 executions into CNF, optionally with native XOR constraints, under parsed A/E/W characteristic rows. The companion decoder reconstructs inputs and prints working states; it is not a complete model or collision certificate verifier.

## Source inspection and available execution evidence

static-source-review; finite-32-bit-gate-and-trace-fixtures-passed; optional-modes-and-solver-campaigns-not-certified.

Encoding stores clauses in Python memory. One tested 39-step free-chain single-execution fixture generated 41,802 variables and 187,833 ordinary CNF clauses; the full encoder makes two executions and adds shape/optional constraints. These are fixture counts, not a complete two-copy instance price or solve-time estimate. Use disposable small examples before generating research-scale formulas.

## Declared inputs

**Encoding positional arguments**: python sha_cnf.py instance.xml out.cnf out.map [chaining]. The exact fourth value iv fixes both initial states to the standard IV. Every other value, including an omitted or misspelled value, takes the free-chain branch; those two initial states need equality pins if a common CV is required.

**XML-like characteristic**: A regex reads name="n" value="digits" and numbered A:/E:/optional W: lines. Duplicate row numbers keep the last occurrence. Rows are not parsed or validated with a full XML schema. No universal final-equality or message-nontriviality requirement is added automatically.

**Bit symbols and orientation**: Default BITORDER=msb maps the first character to the top bit. '-' enforces equality, x enforces inequality, 0/1 pins both bits, and ? or an unrecognized symbol adds no constraint. u/n default to unsigned inequality; SIGNED=1 means u=(1,0), n=(0,1). Short rows constrain only the leading positions; long rows are cropped to the configured width.

**Width and state conventions**: WBITS defaults to 32. Other widths use scaled rotations and truncated constants, defining a separate reduced-width family. A/E rows -1 through -4 represent the initial registers; A/E row t is post-step t. Four terminal A/E rows represent the full working state.

**Environment-sensitive modes**: Preserve WBITS, BITORDER, CHAINREV, SIGNED, KOFF, EXTRAW, SCHED_ONLY, MODDIFF, DIFFVARS, REQUIRE_DIFF, SYMBREAK, XORMODE, XOR3, NEAR_K, NEAR_ENC and NEAR_OUTS. SCHED_ONLY removes the compression recurrence; KOFF offsets encoder round constants; XORMODE requires an XOR-aware solver. Not all settings are stored in the map.

**Decode mode**: python sha_cnf.py --decode out.map model.txt. Integer tokens become literal assignments, later repeated assignments overwrite earlier ones and missing variables default false. The source does not check the complete CNF, row constraints or assignment completeness. The map does not preserve KOFF, and sha_ref always starts with K[0].

## Outputs and interpretation

**CNF and mapping files**: Writes/replaces both explicitly named paths. The formula contains two computations and the selected pins. The JSON maps message, initial-state, row and optional diagnostic variables. A generated formula is not a SAT/UNSAT verdict.

**Decoder text**: Prints both message blocks, initial states, eight-word working states, message inequality and working-state equality. No feedforward is added. An empty model for an unconstrained fixture yields a trivial identical-message pair and outputs equal=True without raising an error.

**Independent publication checks**: 80 Boolean gate truth assignments, 64 shape-symbol assignments and ten 32-bit trace fixtures passed. Traces cover 1,4,17,39 steps and a three-step KOFF=7 case in both ordinary CNF and native-XOR modes. Every generated clause is satisfied by the constructed test valuation, and final states match a separate reference. This is finite positive-fixture validation, not solver completeness or certification of every optional mode.

## Imports

- Python standard library. Encoding requires a small source characteristic; decoding requires its matching map and model. Solving is a separate operation and is not part of these publication checks.

## Worked examples

### Replay the bounded source-contract checks offline

Working directory: The extracted encoder-summary-kit folder

```text
python -I -B replay.py
```

Python 3.10 or later, standard library only. The kit includes the pinned sources and finite data. It writes two small reports inside the extraction folder and uses disposable test directories; no solver or network.

Expected: passed=true; encoder checks include 80 gate assignments, 64 shape assignments, ten traces and four known answers. The demonstrated KOFF mismatch and empty-model trivial output are expected negative controls, not new collision witnesses.

### Generate a one-step standard-IV fixture without solving

Working directory: A new disposable directory containing a copy of the pinned sha_cnf.py

```text
python sha_cnf.py demo.xml demo.cnf demo.map iv
```

Clear inherited encoding-mode environment variables first. demo.xml contains <options><option name="n" value="1"/></options> followed by a new line 0 A: ? E: ? W: ?. The map and formula are newly created outputs, not research inputs to overwrite.

Expected: A one-step two-execution formula with standard-IV starts and no imposed collision target. This demonstrates encoding only; no solver is called and no collision is claimed.

### Interpret a model, then independently validate it

Working directory: A disposable directory with the matching source, map and complete solver model

```text
python sha_cnf.py --decode demo.map model.txt
```

Use only a matching solver result. Independently check every clause and the exact environment-specific computation; do not treat successful process exit or outputs equal=True alone as a certificate.

Expected: Readable message words, chains and working-state comparison. A valid collision claim additionally needs distinct legal messages, the correct initial-state law, feedforward comparison and the intended target domain.

## Failure modes

- Default free chains are not automatically equal. Working-state equality with different CVs does not establish equal feedforward outputs.
- u/n signs are relaxed unless SIGNED=1; unknown symbols add no constraints, and duplicate rows silently overwrite earlier pins.
- SCHED_ONLY makes state rows free diagnostic variables; satisfying that formula does not certify a compression trajectory.
- KOFF=7 is correctly used by the encoder in the tested trace, but the decoder reference ignores it and computes a different state. Independently replay offset experiments with the exact constant window.
- Decoder output is not model validation. Missing, conflicting or unrelated literals can produce numerical text without checking the generating formula.
- Near-collision, totalizer, modular-difference, symmetry-breaking, XOR3 and reduced-width modes are not covered by these finite tests.
- The map alone does not preserve every setting; retain the source hash, environment, characteristic, CNF hash and solver/proof data together.
