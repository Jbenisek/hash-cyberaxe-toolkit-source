# Middle-band scan: configure pins and track resumed searches

Source: `research/game/climber/guided/midscan/mid_driver.py`

Public SHA-256: `e295b1f64fb222d0c87e0994a92181eaa3870f560a7c39c4a93bce9418189cca`

## Reviewed usage contract

Enumerate released characteristic cells with seed witnesses, pin both A/E trajectories over four-row bands, exclude the seed pair, and search for another collision. The distributed program is a historical campaign driver, not a turnkey portable verifier. Its solver/verifier statuses and its saved table must be interpreted separately.

## Source inspection and available execution evidence

static-source-review; isolated-source-function-fixtures-passed; no campaign or SAT solve.

Default scan uses eight Python worker threads and at most one active solver per worker. Each solver has ulimit -t 1200 CPU seconds, not a wall-clock timeout; encoding is uncapped and possible seed derivation adds another solve. The cap argument applies to --one; the main scan uses fixed CAP=1200. Saved solver-wall subtotals exclude other stages and are not a full attack-work ledger.

## Declared inputs

**Layout and imports**: Requires ../kit/sha_cnf.py, ../kit/indep_verify.py, ../relscan/cells, ../../MAP_DATA.jsonl, local witness_src.json and every referenced witness or derivable base XML. It imports sha_cnf at module import. Run-time dependencies include Python 3, Bash, Kissat, nice and writable /dev/shm.

**Modes**: --dry enumerates cells and prints counts but the main block first creates found/. --one CHAR PIECE LO-HI supports --mode real|ctl and --cap S, writing a separate probe ledger. With neither --dry nor --one, it starts a scan immediately; --help is not implemented and would also start the scan. --jobs defaults to 8 and --first reorders named families.

**Enumeration**: Only MAP_DATA rows with group=release, a name in witness_src.json and an existing cell XML are selected. Four-row bands start at 0,2,... while lo<R-3. There are 18 bands for R=38 and 18 for R=39; the latter last band is 34-37, not 35-38. --one does not validate that the requested band comes from that enumeration.

**Formula additions**: Each four-row band appends 512 bit-valued unit clauses: 4 rows x 2 state words (A/E) x 2 copies x 32 bits. No message word is pinned (J=0). In real mode one 1,536-literal clause excludes the combined seed identity: both 256-bit initial states plus both 512-bit messages. The CV remains a free search variable rather than a fixed standard IV; the exact encoder/XML determine all other relations.

**Shared-state hazard**: build assigns module-global CVG, then waits for encoding, then traj reads CVG. A second worker can overwrite CVG during that wait. Band pins can then use a different CV from the local CV used by the seed-exclusion clause. A deterministic four-step fixture changed 263 of 512 pin units under this interleaving while leaving exclusion unchanged. This demonstrates a source-level hazard, not that a particular saved run was affected.

**Environment**: The encoder forces SIGNED=1 and inherits other variables. The exact environment, encoder, characteristic, map and seed hashes are needed for replay. A label sfs does not by itself certify shared-CV or standard-IV conditions.

## Outputs and interpretation

**Ledger**: Appends char, piece, mid=lo-hi, mode, verdict, wall_s, how to RESULTS.tsv; --one uses RESULTS_probe.tsv. BUILDFAIL appends extra exception information and is not the same seven-field schema as normal rows. Recorded wall_s covers the solver subprocess, excluding encoding and post-verification.

**Verification**: Solver return 10 is SAT and 20 is UNSAT; all other exits become UNDECIDED. SAT model v-lines are decoded, required to contain messages differ: True and outputs equal: True, then required to produce INDEP VERIFIED from the separate checker. Success is FOUND, verification failure SAT_NOVERIFY. Text markers do not prove the model satisfies every emitted CNF clause or the intended band pins.

**Files and cleanup**: Workers use /dev/shm/mid_w<worker>.cnf/.map; --one uses its PID in the tag. Two simultaneous scan processes can collide on worker paths. Normal completion removes CNF/map, but exceptions or interruption can leave them. FOUND files omit mode from their filenames and may be overwritten. Derivation may create wit_<char>.json or a persistent .FAILED marker.

**Resume semantics**: The completion key contains only char|piece|lo-hi. Any nonempty verdict except BUILDFAIL is skipped, including UNDECIDED and SAT_NOVERIFY. Mode, cap, seed, environment and formula hashes are absent. A control row copied into the main ledger can suppress the matching real run; raising a budget does not automatically retry censored rows.

## Imports

- Publication tests extract six named source functions with AST and use a synthetic four-step map and stub encoder. The full module is never imported or launched, so passing those fixtures is not full-campaign certification.
- A faithful campaign replay needs its original MAP_DATA, witness catalogue, XMLs, seed data, exact encoder/verifier, environment and solver version. The public record does not establish those as a complete validated bundle.

## Worked examples

### Inspect available modes without triggering the driver

Working directory: A directory containing the exact archived mid_driver.py

```text
python -c "import ast; from pathlib import Path; t=ast.parse(Path('mid_driver.py').read_text()); print(', '.join(n.name for n in t.body if isinstance(n,ast.FunctionDef) and n.name.startswith('do_')))"
```

Expected: Prints do_dry, do_one, do_scan. It parses source text only; unlike --help it cannot launch a scan.

### Compute the documented 39-step band enumeration

Working directory: Any disposable directory with Python

```text
python -c "b=[(lo,lo+3) for lo in range(0,39-3,2)]; print(len(b),b[0],b[-1])"
```

Expected: Prints 18 (0, 3) (34, 37). This is a teaching calculation, not execution of the campaign or an assertion that all bands are satisfiable.

### Replay the isolated dependency and resume checks

Working directory: A disposable directory containing the linked check_midscan_functions.py and exact archived mid_driver.py

```text
python -B check_midscan_functions.py --source mid_driver.py
```

Expected: Prints passed: true in a JSON report, 512 control pin units, a 1,536-literal real exclusion and 263 changed pins in the controlled interleaving. It extracts six named functions into a fixture with a stub encoder; it never imports the campaign, launches a solver or touches original result files. Altered source bytes and Python -O are rejected.

## Failure modes

- Do not use --help: no argument parser exists and it starts the default scan.
- Do not treat UNDECIDED as UNSAT or assume resume revisits it at a larger budget.
- The global CVG race can invalidate intended seed-derived pins across threads. Avoid scientific conclusions about a saved run without inspecting its retained exact formula and seed.
- Successful digest verification and correct constraint-generation are different checks; one does not imply the other.
- Formula cleanup means the ordinary output may not retain the evidence needed for that audit.
- No full campaign was launched, repaired or certified for this publication. Original research remains unchanged.
