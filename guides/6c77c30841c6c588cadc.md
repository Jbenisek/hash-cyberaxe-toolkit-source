# Expanded-word profiles: inspect signed differences and XML projections

Source: `research/tools/schedexact/wdiff_profile.py`

Public SHA-256: `0903e60a9c7759289300ba1b95fbb0d95a92bb60d3f15a1ffc4ba6b4a23b437f`

## Reviewed usage contract

Expand validated M1/M2 words and report literal signed schedule differences, or deliberately project only u/n symbols from XML text.

## Source inspection and available execution evidence

static-source-review; finite-expansion-sign-and-XML-projection-checks-passed; not compression verification.

Linear expansion through the requested finite R. Bounded checks cover 515 full-width message vectors, 64 ordered-bit cases and a lossy-XML fixture.

## Declared inputs

**PAIRFILE R**: M1 and M2 lines each contain sixteen hexadecimal 32-bit words; validate 1<=R<=64 independently. Source masks parsed integers to 32 bits and ignores later tokens.

**--xml CHAR.xml**: Scans physical lines containing W:. Keeps only lowercase u/n; other markers become dashes. Original row labels are discarded. This is not a general XML parser or complete difference profile.

## Outputs and interpretation

**Sign and dmod**: u means M1=1/M2=0; n means M1=0/M2=1. dmod is M1-M2 modulo 2^32 in a signed representation. The leftmost character is bit 31.

**Footer**: Active rows and bits, last differing row, and R-1-lastdiff. In XML mode R is the number of extracted strings, not the configured target steps.

## Imports

- Python standard library; no solver or network.

## Worked examples

### Create and inspect a synthetic schedule pair

Working directory: Disposable folder containing the downloaded wdiff_profile.py

```text
python -c "from pathlib import Path; Path('fixture.pair').write_text('M1 '+' '.join(['00000000']*16)+'\nM2 00000001 '+' '.join(['00000000']*15)+'\n')"
python wdiff_profile.py fixture.pair 48
```

Expected: Row 0 differs at bit 0 with symbol n and dmod=-0x1. Later schedule differences and a footer are printed. This fixture is not a compression collision.

### Inspect the signed-symbol projection only

Working directory: Folder containing a validated characteristic and the downloaded tool

```text
python wdiff_profile.py --xml CHAR.xml
```

Expected: Only u/n survive. Do not interpret dropped x/?/0/1 or sequential row numbers as the original characteristic's full semantics.

## Failure modes

- XML x-only differences disappear.
- XML row labels are replaced by sequential positions.
- A silent message schedule suffix does not imply equal states or free compression rounds.
- No chaining value, padding, digest or attack-price verification is performed.
- Input ranges and complete row format require separate validation.
