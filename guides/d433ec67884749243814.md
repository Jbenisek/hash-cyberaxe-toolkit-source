# Saved-witness diagnostic: recompute four fixed pairs

Source: `research/retest/four_pattern_contradiction/verify_alts.py`

Public SHA-256: `697fc57c17b2be84b34ccb90b23e16fb121cdd8e2f796f8cd1319e9a1b55b8d3`

## Reviewed usage contract

Load four fixed JSON records, recompute reduced SHA-256 outputs under each common CV, and print equality plus selected side-A E bits. This is a diagnostic wrapper, not a fail-closed certificate checker.

## Source inspection and available execution evidence

static-source-review; four-pair-two-reference-replay-and-eight-interface-controls-passed.

Eight 37-step compressions in the historical wrapper, plus fixed file reads. The portable kit adds bounded controls and two-reference checks. Neither counts the original witness discovery cost or estimates an attack success rate.

## Declared inputs

**No CLI parameters**: Uses two hardcoded WSL path literals pointing to research/tighten/r37_unforced_files. Extra arguments do not select different files. The portable kit changes only these literals in a disposable copy.

**Fixed JSON files**: alt_G1_verify.json, alt_G2_verify.json, alt_G12_verify.json and i_all52_verify.json. Each needs CV (8 hex words), MX and MY (16 hex words each). The wrapper itself does not enforce canonical ranges, these sizes or nontriviality; the bounded replay adds those checks.

**Reference**: Imports the adjacent sha256_ref module. The pinned kit supplies that module and a second independent implementation, rather than trusting a module from an unrelated search path.

## Outputs and interpretation

**Console**: One equality line per record plus (row, E[1], E[10], E[29]) tuples at zero-based rows 17 and 18. Row t is the state after step t. No witness or output file is written by this wrapper.

**Meaning**: All four saved pairs collide at 37 steps under their own common chosen CV. None uses the standard IV. Side-A (E18[1],E18[10]) equals 10, 01, 00, 00: four witnesses cover three patterns, not four.

## Failure modes

- A mutated message prints False but the wrapper exits zero.
- Identical messages print True; this does not establish a nontrivial collision.
- Saved digest, collision, flipped-value and constraint flags are not verified by the wrapper.
- Missing or malformed input can fail after partial positive output. Require the complete record set and final status.
- Do not run sha256_ref.py as its unrelated historical main driver: it expects other files and writes traces.
- The finite checks do not replay the historical large sampled retest, audit every characteristic cell, or prove all four patterns occur with equal probability.
