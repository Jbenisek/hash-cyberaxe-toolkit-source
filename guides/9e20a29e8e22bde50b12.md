# Generic Orchard Poseidon rho: explore walks and the cost planner

Source: `research/poseidon/generic/pkg/experiments/rho.py`

## Reviewed usage contract

This early generic candidate evaluates the complete Orchard Poseidon hash, with eight full and 56 partial rounds, while its two organizer experiments detect only short digest-prefix matches. It contains a single-trail distinguished-point recovery algorithm and a separate floating-point cost planner. Full-round hash evaluation does not make a reduced-prefix pair a full-output collision.

## Source inspection and available execution evidence

static-source-review; copied finite digests, 49,152 synthetic graph controls, search-free planner and stubbed interface checks; original searches not executed.

The example performs 60 numerical planner iterations and formatting, with no Poseidon evaluations. The reduced rho helper permits at most 256+3*160=736 logical map calls under its supplied caps; its cache can reduce fresh digest computations. The projection mode performs at most 64 digests. These finite experiment bounds are not the declared full-target attack price.

## Declared inputs

**Request and experiment dispatch**: The JSON route expects experiment_id and trials, each with seed and caller trial keys. Exactly rho-n14 selects run_rho. Every other experiment_id selects run_proj, including misspellings. schema_version, target_profile and event are not validated. An empty trials list is a safe parser check, not a successful experiment.

**Seed and message encoding**: Seeds are parsed with int(seed,16). rho-n14 reduces the seed modulo 2^14. The projection route shifts the parsed seed right by two; its stated 254-bit canonical start assumes a nonnegative seed of at most 256 bits, a condition the parser does not enforce. Returned messages encode x as 32 little-endian bytes followed by 32 zero bytes. enc asserts 0 <= x < P; do not disable assertions.

**Target hash**: P is the Pallas modulus. The initial state is [x,0,2^65]; rounds 0..3 and 60..63 apply fifth powers to all three words, rounds 4..59 only to the first. Each round adds its constants and applies the fixed 3-by-3 MDS. The digest is final state[0], with no feed-forward. All 64 constant rows and the MDS match the independent replay bundle.

**Entry points**: main is guarded, so import does not start a walk. --plan computes and prints a numerical model without hash searches. --selftest runs 40 reduced-width searches and is not the bounded example. An unknown command-line option returns with exit code zero and no output; check the requested mode and output, not exit status alone.

## Outputs and interpretation

**rho-n14 result**: The map is F_n(v)=digest(v,0) mod 2^14. Its distinguished set is values below 1,024, density 1/16. A trial calls search with 256 main steps, 64 stored distinguished points and recovery gap cap 160. Returned pairs have equal low 14 digest bits, not necessarily equal full digests. An unsuccessful trial returns null message fields and a status.

**Projection result**: The projection route walks full-width field values for at most 64 digest evaluations, remembering low 10 digest bits. It returns distinct predecessor messages when their projected digests match. Status pair includes a zero-based j; status none has no j or evaluation total. This is a 10-bit event, despite evaluating all rounds of the hash.

**Recovery status and evaluations**: The search helper returns found, steps, table, gap or start-on-cycle. Its evals count includes calls to the supplied map during the main walk and recovery. In rho-n14, a process-global cache can answer repeated map calls without a new digest calculation, even across trials. Therefore evals is a logical map-call count, not a count of newly computed hashes or a complete machine-operation charge.

**Planner is not an exact certificate**: plan uses binary floating-point exp, log, sqrt and 60 fixed-point iterations, then rounds the main n upward on a 2^100 grid. It emits theta, caps, a model success_lower_bound, T_units and time_log2. The declared field-target table capacity is 16,384; C_UNIT is 1,392. Reproducing those floats does not certify an outward-rounded lower bound, exact integer work charge or fixed-map probability law.

**What the bounded audit establishes**: Six fixed full-round digests agree with the independent checker, and all 11 retained full-round hash vectors match. The recovery helper was tested on all 256 functions on four nodes, all 16 distinguished subsets, four starts and three cap configurations: 49,152 synthetic cases. All 6,672 returned pairs are distinct with equal images, and reported evals equals actual calls. These are synthetic graph cases, not Orchard collision discoveries or field-size probability evidence.

## Failure modes

- A misspelled experiment_id silently selects the projection experiment rather than rejecting the request. Verify mode and event independently.
- A normal process exit can have no output for an unknown option, or return null pairs. Neither is a collision certificate.
- --selftest is a 40-search experiment, not a syntax-only test. It was not run for this publication audit.
- The constant 56 counts partial rounds; the complete permutation has 64 rounds including eight full rounds. Short output events do not shorten that permutation.
- Canonicality is enforced by enc assertions, not by the digest helper. Projection seed width and sign assumptions are not checked at input.
- Cached map calls, fresh digest evaluations, interpreter runtime and charged machine operations are different quantities.
- Floating-point success_lower_bound is a label in a model, not a certified mathematical lower bound. Keep random-mapping and cutoff premises separate.
- This early one-trail candidate is not the later packed-birthday implementation. Do not mix their registers, kernels or ledgers.
