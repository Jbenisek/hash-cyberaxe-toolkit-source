# BLAKE3 r2 frontline: B3Z6 counter search and returned half-digest controls

Source: `research/checks_1015/pa_src/B3Z6/experiments/frontline.py`

Public SHA-256: `c15003ab2e029deed4463dc6ded01a23d5c5338eba6b0b4401ea3d4a5471af89`

## Reviewed usage contract

The program exercises the two-round 55/63-byte construction with exact-borrow gating, packed Y9 caching, descriptor-selected partners and a metered joint solver. A default trial visits selected representative batches, not every member of the class. The returned JSON pair belongs to a separately rebuilt counter-zero, flags-11 root instance. This guide distinguishes that output from any counter-dependent full collision checked internally.

## Source inspection and available execution evidence

static-source-review; Copied finite initialization, direct construction, packed/table fixtures and mocked dispatch; no walk, trial, plant or original selftest.

The source-bound finite checker gives each isolated worker and empty-CLI control a45-second ceiling. No duration is promised for nonempty requests or --selftest; setting its random-fixture count to zero does not disable its fixed research drills.

## Declared inputs

**Edition-specific lookup and charge**: B3Z6 uses lane-native R1/L1 for T1, adds two modeled operations per E lane and includes a sixteen-operation opened-cluster entry/return term. Its imported ledger numerator is 3162212250308201329187. These are source-accounting constants, not newly certified complete attack prices.

**Strict request header**: schema_version must be 1, target_profile must be blake3-r2-prefix-v1, event.kind must be digest-xor-mask, and experiment_id must be frontline-search. Missing required keys raise ordinary Python errors; the checker reproduces rejection of four invalid headers. Other event fields are not validated by main.

**Trial inputs**: Each trial contains trial and seed. seed is decoded by bytes.fromhex; it is not an arbitrary text seed. The trial number determines whether the planted joint-root diagnostic runs (every eighth trial). Nonempty requests therefore do real research work.

**Sampled context window**: TRIAL_REPS=5 visits representative batches 0,1,2,3 and the final four-lane batch 2340, at most thirty-two clusters before early termination. A cluster contains thirty-two members; gates may skip work. This is not all 2341 representative batches or all 2^19 class members.

**Import is work**: Import expands fixed member-coordinate tables, constructs finite carry automata and transition arrays, computes constants and compiles scalar expression functions. An empty request runs this setup but no walk, sampler or planted-root search. --selftest 0 still performs substantial fixed checks and research walk drills.

## Outputs and interpretation

**Returned root pair**: trial always constructs a 55-byte and a 63-byte pair with counter zero and flags 11 from the context and first passing member (member zero when none passed). root_pair checks equality only of output words 0,2,5,7. The returned pair is a half-digest control, not necessarily a full 256-bit collision.

**Internally certified counter pair**: The internal steps23 route can verify a full digest collision for flags 3 and a nonzero counter, then stop the walk through Found. walk catches that exception; trial returns its separately constructed root pair instead. A certified observation therefore must not be attached unqualified to the JSON pair.

**Independent finite controls**: Seventeen counter-zero, flags-11 message cases agree with the separate JavaScript implementation on the two-round digest and final-column state. Two full-seven-round known-answer controls gate that implementation. Five fixed direct root pairs agree on the four selected words; none is a full collision. No search rate is inferred.

**Packed and table controls**: Sixteen seven-lane batches give 1008 packed-versus-scalar word comparisons. Thirty-two fixed words agree between both carry tables and their bit-serial definitions; 224 lane-address controls check the edition-specific lookup path. These are finite checks, not a universal proof of gate losslessness, all solver branches or complete work accounting.

**Observations**: members, e_lanes, passes, solver_calls, leaves, roots, certified, units, solver_units, opened, closed, skipped_pass, checks, mismatches, fills and halted describe the instrumented trial. Interpret mismatch counts explicitly. A successful JSON serializer does not assert all of them are zero.

**Ledger scope**: N, budgets and operation terms are asserted by the source during import. The publication checks those finite asserted constants and layout differences but does not discharge the inherited success, mass, cap, preprocessing or machine-layout premises.

## Failure modes

- Do not compare the returned root-instance pair with the counter-search certificate without reconciling flags and counter. They are different objects.
- A four-word digest agreement is not a full eight-word collision, and a matching observation counter is not a witness verifier.
- main validates event.kind but not a complete event-mask specification. The consuming harness must check the requested digest relation independently.
- walk(nr=0) still schedules the final representative batch. It is not a no-work control; use the validated empty JSON request instead.
- The source retains direct reference recomputation and validation calls alongside charged paths. Python wall time is not the asserted primitive-operation ledger.
- Invalid hex seed strings fail during decoding. Negative/duplicate trial numbers have no complete domain validation in main.
- Do not run selftest, plant, trial or walk merely to inspect a source contract. The bounded publication fixtures deliberately avoid them.
- Preserve exact edition hashes and inherited attribution; these two files share a name but change lookup layout and charge terms.
- Assertions are disabled by python -O; use normal Python for evidence controls.
