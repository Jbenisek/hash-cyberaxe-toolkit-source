# Free the state prefix before a pinned band

Source: `research/game/climber/guided/newwords/nw2.py`

Public SHA-256: `de9c21a9bba2efb917f0905ba9f6a0c7908d7d7d708be8522cf5fc98b8c4350b`

## Reviewed usage contract

With an explicit band, frees all nonnegative A/E rows before the band's start, while retaining initial and later state rows. All three versions free every nonnegative W characteristic row. The teaching kit tests the text transformations on synthetic fixtures; it does not claim that those fixtures are collisions or satisfiable characteristics.

## Source inspection and available execution evidence

static-source-review; bounded-synthetic-text-transformations-passed; full build and solver search not certified.

The tested operation rewrites a bounded text fixture: O(N) rows with fixed 32-character words. The full build is larger and retains encoder clauses in memory; no solver CPU cap or complete operation charge is supplied by this module. The teaching wrapper launches only bounded Python transformation checks.

## Declared inputs

**Startup and dependencies**: Import sets process environment SIGNED=1, modifies sys.path and imports char_pair_profile from ../kit. It does not call the build method until requested. The teaching kit includes this imported module but does not use its collision profiler in the synthetic test.

**mkchar and version semantics**: mkchar(name,out,band=None). For band b1619, state rows 0..15 become free. The initial rows -4..-1 and rows at/after 16 remain unchanged. A question mark permits either equality or inequality; it does not force a difference.

**Characteristic lookup**: Named inputs are pub39, llw39, mns38 and hyb38. OWN maps them to historical XML files under ../chars. The synthetic teaching fixture supplies only a temporary hyb38 shape and deletes it afterwards. These tests do not certify the historical input corpora.

**Full build signature**: build(name,band,mode,outbase) or CLI nw2.py PAIR BAND MODE OUTBASE. Bands are b0811 (8..11), b1215 (12..15) and b1619 (16..19). The build resolves a real witness, checks its profile's collision flag, writes a derived XML, encodes two trajectories, and pins both copies' A/E values across four rows.

**Missing full-campaign inputs**: The build additionally needs sha_cnf.py, matching characteristic XML and the angle_*_WITNESS.json corpus under a computed outside/kepler_in path. This lesson is not a complete build/search package. A source lookup for a real witness cannot be replaced by the synthetic fixture.

**char CLI caveat**: The char NAME OUT branch calls mkchar without a band. It therefore leaves every A/E row unchanged, despite the module's band-based behavior. Use the API with an explicit band for the state relaxation.

## Outputs and interpretation

**Changed text**: All nonnegative W rows are replaced with 32 question marks. The regex-derived A/E rows are otherwise preserved except for this version's stated state relaxation. Negative initial-state rows retain their input relation. The header n is copied; no arbitrary XML/schema validation is performed.

**Full build files and seed exclusion**: Writes or overwrites outbase.xml, outbase.cnf and outbase.map; parents must exist. Four rows at 32-bit width add 512 unit pins. Only mode exactly real adds one 1024-literal clause excluding the ordered pair of sixteen-word messages. CVs are not part of this exclusion; other mode spellings behave as no exclusion.

**What the label does not establish**: The sfs encoder label alone does not equate CVs; the underlying characteristic must impose the relation. The module forces SIGNED=1 but does not clear other experimental encoder variables. Witness R and XML n are separately read, not explicitly required equal. A successful generation is not SAT, digest equality or a complete attack price.

**Bounded evidence**: Nine synthetic transformations cover all three variants and three bands. Two char CLI controls confirm that nw2/nw3 omit the band and preserve A/E rows. The archive test rejects a modified source before import. Full build methods, solver behavior and any historical success rate remain outside this evidence.

## Failure modes

- Do not mistake question marks for required nonzero differences.
- Copied comments are not authoritative: nw3 implements only the four-row prefix window.
- The char CLI in nw2/nw3 supplies no band and does not exercise the state relaxation.
- Full build requires real inputs absent from this teaching lesson; a synthetic shape is not a substitute for a valid seed.
- Source imports change SIGNED and sys.path; use an isolated process.
- Other inherited encoder switches can change width, constants, schedule-only behavior or the target.
- Do not use Python -O: it removes the source's seed-collision assertion.
- Full build redirects stdout without a try/finally; an encoder exception can leave its process output redirected.
- Empty mode validation means a misspelled real does not add the intended seed exclusion.
- Finite text checks establish no search probability, novel pair or attack-cost reduction.
